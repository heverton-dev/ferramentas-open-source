Introdução

Prefácio: A Crise do Desenvolvimento com IA

O desenvolvimento de software com IA sem arquitetura enfrenta quatro catástrofes: faturas de tokens astronômicas, amnésia de contexto (Lost in the Middle), alucinações de validação e fragmentação entre IDEs.

Este Tratado ensina como transformar o caos de chats soltos em uma esteira industrial de precisão cirúrgica, controlando as 4 camadas do agente: TELA, HARNESS, LLM e TOOLS.

Fundamentos

O Dicionário do Iniciante (Glossário Descomplicado)

Token & KV-Cache: O token é a moeda da IA (~4 letras). O KV-Cache permite reaproveitar o cálculo do prompt congelado, gerando até 90% de desconto na API.
Pre-Commit Hook: Um "segurança digital" no computador que inspeciona o código antes do salvamento e bloqueia o commit se houver falhas.
Hardlink / Junction: Portais mágicos do sistema operacional que fazem um mesmo arquivo físico aparecer em várias pastas de IDEs diferentes sem duplicação.
Circuit Breaker: Disjuntor que desliga a IA automaticamente se ela entrar em loop infinito de erros.

Consultorias de IA

Pipelines de Dados

Capítulo 1

Camada 1: TELA (Prompt & Context Engineering)

Princípios Imutáveis: Invariância de Prefixo (KV-Cache), Densidade de Shannon (Zero Entropia Prolixa) e Localidade de Contexto.

Blindagens da TELA 100% Conforme
  • Constituição Mestre: 18 regras inegociáveis (R1 a R18) purificadas em .claude/CLAUDE.md.
  • 5 Skills de Economia Severa: caveman (-90% pensamento), headroom, lean-ctx, rtk-memory, pre-flight-check.
  • Vocabulário Controlado: Banimento de clichês de IA em favor de respostas densas.
  • Gate da TELA: python scripts/auditar_camada_tela.py (Exit 0).
Capítulo 2

Camada 2: HARNESS (Orquestração & Segurança)

Princípios Imutáveis: Disjuntor & Parada de Loop (Halting Problem), Privilégio Mínimo e Ponto Único de Verdade.

Blindagens do HARNESS 100% Conforme
  • Circuit Breakers em settings.json: Limite de 25 iterações e timeout de 60s.
  • Pre-Commit com 6 Gates: Segredos (R15), Testes (R16), Sintaxe, Grafo e Higiene (R18).
  • Portabilidade Multi-IDE: Hardlinks para Cursor, Windsurf, VS Code e Claude Code.
  • Gate do HARNESS: python scripts/auditar_camada_harness.py (Exit 0).
Capítulo 3

Camada 3: LLM (Model Layer & Semantic Routing)

Princípios Imutáveis: Roteamento por Pareto de Custo/Capacidade, Type Safety via Structured Outputs e Degradação Graciosa.

Blindagens do LLM 100% Conforme
  • Matriz de 3 Tiers: Tier 1 Flash (1x custo), Tier 2 Sonnet (10x), Tier 3 Pro (30x).
  • Contratos JSON Schema: scripts/schemas/ para tipagem estrita de saídas.
  • Registro Declarativo tipos.py: Custo de LLM associado a cada artefato (R12).
  • Gate do LLM: python scripts/auditar_camada_llm.py (Exit 0).

Capítulo 6

Manual de Montagem Universal em 5 Minutos

# 1. Iniciar repositório Git
mkdir meu-projeto && cd meu-projeto && git init

# 2. Adicionar o submódulo da Fábrica Universal
git submodule add https://github.com/Heverton-web/fabrica-universal.git fabrica-universal
git submodule update --init --recursive

# 3. Copiar infraestrutura base
cp -r fabrica-universal/.claude .
cp fabrica-universal/RTK-SCRATCHPAD.md .
cp fabrica-universal/.mcp.json .
mkdir -p scripts && cp -r fabrica-universal/scripts/* scripts/

# 4. Criar links e instalar o hook de proteção
powershell .\scripts\setup-links.ps1 meu-projeto   # Linux: bash scripts/setup-links.sh meu-projeto

# 5. Executar a Super-Auditoria
python scripts/auditar_todas_camadas.py
