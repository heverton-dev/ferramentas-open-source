Prefácio: A Crise do Desenvolvimento com IA

Programar com IA sem governança gera 4 catástrofes: faturas astronômicas de tokens, amnésia progressiva (Lost in the Middle), alucinações de validação e fragmentação entre IDEs.

Este Tratado estabelece o padrão industrial para resolver essas dores através de 4 camadas: TELA, HARNESS, LLM e TOOLS.

Fundamentos

O Dicionário do Iniciante (Glossário Descomplicado)

Token & KV-Cache: Token é a unidade cobrada (~4 letras). O KV-Cache aproveita cálculos anteriores se o prefixo de instruções for mantido 100% congelado, gerando até 90% de desconto.
Pre-Commit Hook: Script que inspeciona o código antes de qualquer commit no Git, bloqueando segredos e testes quebrados com exit 1.
Circuit Breaker: Disjuntor no software que interrompe a execução da IA se ela entrar em loop infinito.

Capítulo 2

Camada 2: HARNESS (Orquestração & Segurança)

Princípios Imutáveis: Disjuntor & Parada de Loop (Halting Problem), Privilégio Mínimo e Ponto Único de Verdade.

  • Circuit Breakers: Limite de 25 iterações e timeout de 60s em settings.json.
  • Pre-Commit com 6 Gates: Segredos (R15), Testes (R16), Sintaxe, Grafo e Higiene (R18).
  • Portabilidade Multi-IDE: Hardlinks para Cursor, Windsurf, VS Code e Claude Code.
Capítulo 3

Camada 3: LLM (Model Layer & Semantic Routing)

Princípios Imutáveis: Roteamento por Pareto de Custo/Capacidade, Type Safety via Structured Outputs e Degradação Graciosa.

  • Matriz de 3 Tiers: Tier 1 Flash (1x custo), Tier 2 Sonnet (10x), Tier 3 Pro (30x).
  • Contratos JSON Schema: scripts/schemas/ para tipagem estrita de saídas.
  • Registro Declarativo tipos.py: Custo de LLM associado a cada artefato (R12).
Capítulo 4

Camada 4: TOOLS (MCP Servers & Determinismo Mecânico)

Princípios Imutáveis: Separação de Responsabilidades (LLM Pensa, Tool Executa), Idempotência Algorítmica e Paridade Criptográfica de Hash.

  • Banco de Estado SQLite R11: estado_esteira.db que registra sessões e auditorias.
  • Compilador Diamante Oficial: scripts/compilar_compendio_diamante.py.
  • Usina Determinística: Saneador automático, fiscal DOM e auditores Python.

Capítulo 6

Manual de Montagem Universal em 5 Minutos

# 1. Iniciar repositório Git
mkdir meu-projeto && cd meu-projeto && git init

# 2. Adicionar o submódulo da Fábrica Universal
git submodule add https://github.com/Heverton-web/fabrica-universal.git fabrica-universal
git submodule update --init --recursive

# 3. Copiar infraestrutura base
cp -r fabrica-universal/.claude .
cp fabrica-universal/RTK-SCRATCHPAD.md .
cp fabrica-universal/.mcp.json .
mkdir -p scripts && cp -r fabrica-universal/scripts/* scripts/

# 4. Criar links e instalar o hook de proteção
powershell .\scripts\setup-links.ps1 meu-projeto   # Linux: bash scripts/setup-links.sh meu-projeto

# 5. Executar a Super-Auditoria
python scripts/auditar_todas_camadas.py
