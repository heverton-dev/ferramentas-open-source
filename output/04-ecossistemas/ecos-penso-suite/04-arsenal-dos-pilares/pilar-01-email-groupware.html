Mailcow: dockerized · Suíte Moderna de E-mail Corporativo com Rspamd, SOGo Groupware e ActiveSync

Persona: Robusta Substitui: Penso Mail Enterprise / Zimbra Network Edition R$ 24.000/ano GPL-3.0
1. O Que Faz & Como Funciona

Gerencia caixas postais corporativas, filas SMTP, roteamento de domínios e proteção antispam com aprendizado bayesiano. Orquestração em contêineres Docker interligados por rede interna, utilizando Postfix para MTA, Dovecot para IMAP/LMTP, Nginx para proxy reverso e SOGo para webmail e groupware.

git clone https://github.com/mailcow/mailcow-dockerized && cd mailcow-dockerized && ./generate_config.sh && docker compose up -d
2. Análise Econômica & Racional
SaaS SubstituídoPenso Mail Enterprise / Zimbra Network Edition
EconomiaR$ 24.000/ano
Racional

Solução conteinerizada líder mundial com arquitetura modular, atualizações automáticas via script, suporte nativo a 2FA/FIDO2, ActiveSync para dispositivos móveis e integração direta com Rspamd.

3. Infraestrutura & Veredito
RAM4 GB
Dockermailcow/postfix:latest
Veredito

A escolha mais sólida e testada em batalha para substituição direta de servidores Zimbra corporativos com zero perda de recursos.

4. Guia Prático em 3 Passos
1 Configuração de DNS Autoritativo

Crie registros MX, SPF (v=spf1 mx ~all), DKIM e DMARC (v=DMARC1; p=quarantine) no provedor DNS do domínio corporativo.

2 Provisionamento do Mailcow

Execute generate_config.sh informando o FQDN (mail.empresa.com.br) e suba o cluster com docker compose up -d.

3 Criação de Caixas Postais & Migração

Acesse a interface de administração, configure o domínio e utilize o módulo de sincronização IMAP (Syncjob) para puxar as mensagens do Zimbra antigo.

5. White-Label
Mecânica

Customização de logos, cores institucionais e favicon diretamente via painel administrativo do Mailcow.

Manutenção

Persistente entre atualizações de contêineres através de volumes mapeados.

6. Ecossistema Agêntico & MCPs

Automação de provisionamento de caixas postais via terminal

https://github.com/mailcow/mailcow-cli

Conector Oauth2/IMAP para leitura de mensagens no painel da nuvem
