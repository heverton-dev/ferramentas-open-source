Prefácio: Por Que a Fábrica Universal Existe?

A Fábrica Universal transforma a programação assistida por IA em uma esteira industrial previsível, eliminando faturas de tokens caros, amnésia de contexto e alucinações de validação.

Fundamentos

O Dicionário do Iniciante (Glossário Descomplicado)

Token & KV-Cache: O combustível da IA cobrado por palavra. O KV-Cache garante até 90% de desconto quando o início das instruções é mantido 100% congelado.
Pre-Commit Hook: Um "segurança digital" no computador que inspeciona o código antes de salvar.
Exit Code (0 ou 1): A linguagem binária do computador: Exit 0 = Aprovado / Exit 1 = Reprovado.
Capítulo 1

O Motor de Economia Severa de Tokens

5 técnicas que reduzem de 50% a 90% dos custos em qualquer IA:

  • Caveman Thinking: Raciocínio telegráfico no pensamento interno.
  • Headroom: Corte inteligente de logs longos (3 no topo + 4 no fim).
  • Lean-CTX: Busca via grep antes de ler arquivos inteiros.
  • RTK-Memory: Prompt congelado e aprendizados em RTK-SCRATCHPAD.md.
  • Pre-Flight Check: Checklist pré-voo antes de refatorar.

A Usina de Scripts Determinísticos (`scripts/`)

  • scripts/hooks/pre-commit: O fiscal com 6 gates de auditoria.

Capítulo 4

Portabilidade Multi-IDE: Uma Fonte, Todos os Ambientes

A governança vive exclusivamente em .claude/CLAUDE.md. O script setup-links cria Hardlinks diretos para que Cursor, Windsurf, Cline, VS Code e Copilot leiam exatamente a mesma regra no disco físico sem duplicação.

Capítulo 6

Manual Prático de Implementação

# 1. Iniciar repositório Git
mkdir meu-projeto && cd meu-projeto && git init

# 2. Adicionar o submódulo da Fábrica Universal
git submodule add https://github.com/Heverton-web/fabrica-universal.git fabrica-universal
git submodule update --init --recursive

# 3. Copiar governança e scripts
cp -r fabrica-universal/.claude .
cp fabrica-universal/RTK-SCRATCHPAD.md .
cp fabrica-universal/.mcp.json .
mkdir -p scripts && cp -r fabrica-universal/scripts/* scripts/

# 4. Criar links e instalar o hook de proteção
powershell .\scripts\setup-links.ps1 meu-projeto # Linux: bash scripts/setup-links.sh meu-projeto

# 5. Executar a Super-Auditoria
python scripts/auditar_todas_camadas.py
