Prefácio: Por Que a Fábrica Universal Existe?

Imagine que você contratou um assistente muito inteligente para ajudá-lo a construir uma casa. Porém, esse assistente tem três características perigosas:

  • Ele cobra por cada palavra que lê e pensa: Se ele pensar de forma prolixa e longa, sua conta bancária é esvaziada em minutos.
  • Ele é esquecido: Conforme o dia passa e a conversa fica longa, ele começa a esquecer o que combinou no início da manhã.
  • Ele sofre de excesso de confiança (alucinação): Às vezes, ele afirma com certeza absoluta que executou uma tarefa perfeitamente, mas na verdade o código nem compila.

A Fábrica Universal nasceu para resolver exatamente esses três problemas no desenvolvimento de software com Inteligência Artificial (chamado de AIDD ou AI-Driven Development). Ela cria uma esteira industrial com trilhos de aço que reduz custos em até 90% e garante qualidade mecânica à prova de falhas.

Fundamentos

O Dicionário do Iniciante (Glossário Descomplicado)

Para que qualquer leitor compreenda todos os conceitos, aqui estão as definições dos termos essenciais:

Token: O combustível e a moeda de cobrança da IA. Um token é aproximadamente 4 letras de uma palavra. Você paga por cada token enviado e por cada token recebido.
Contexto (Context Window): A "memória de curto prazo" da IA. Tudo o que ela consegue enxergar de uma vez só durante a conversa.
CoT (Chain of Thought): O rascunho mental onde a IA raciocina em silêncio antes de dar a resposta final.
Hook do Git (Pre-Commit): Um "segurança digital" no computador que inspeciona o código antes de salvar. Se houver falha, ele bloqueia o salvamento na hora.
Exit Code (0 ou 1): A linguagem binária do sistema operacional. Exit 0 = Sucesso/Aprovado. Exit 1 = Erro/Reprovado.
Capítulo 1

O Motor de Economia Severa de Tokens

Como a Fábrica Universal economiza de 50% a 90% de custos em qualquer modelo de IA:

1. Caveman Thinking (Pensamento Telegráfico)

Força a IA a raciocinar em estilo telegráfico no seu bloco interno <thought>, cortando palavras vazias e mantendo a resposta final impecável.

// Pensamento Tradicional (~250 tokens):
"O usuário gostaria de verificar se existem erros no arquivo de configuração..."

// Pensamento Caveman (~25 tokens - Economia de 90%):
"usr quer ver config. linha 42. ler 10 linhas. achar bug. corrigir."

2. Headroom (Compressão de Logs)

Se um log de terminal tiver mais de 7 linhas, entrega apenas as 3 primeiras linhas e as 4 últimas, evitando estourar a memória da IA com saídas gigantescas.

3. Lean-CTX (Leitura Cirúrgica)

Proíbe ler arquivos inteiros de 2.000 linhas. Usa grep_search para localizar a linha exata e lê apenas um bloco de 20 a 40 linhas ao redor.

Capítulo 3

A Usina de Scripts Determinísticos (`scripts/`)

A pasta de scripts que transforma regras abstratas em garantias mecânicas:

  • scripts/hooks/pre-commit: O fiscal que roda 6 gates de auditoria antes de cada salvamento.
  • scripts/auditar_higiene_repo.py: Valida se não há scripts temporários ou espelhos dessincronizados.
  • scripts/limpar_entulho.py: Auto-faxina que remove arquivos órfãos e ressincroniza o projeto em 1 comando.
  • scripts/auditar_r5_dossie.py: Fiscal que garante que todas as 49 listas cumpram o padrão Diamante.
Capítulo 4

Portabilidade Multi-IDE: Uma Fonte, Todos os Ambientes

A governança vive exclusivamente em .claude/CLAUDE.md. O script setup-links cria Hardlinks diretos para que Cursor, Windsurf, Cline, VS Code e Copilot leiam exatamente a mesma regra no disco físico sem duplicação.

Capítulo 6

Manual Prático de Implementação

Como iniciar um projeto novo ou salvar um projeto antigo em 5 minutos:

# 1. Iniciar repositório Git
mkdir meu-projeto && cd meu-projeto && git init

# 2. Adicionar o submódulo da Fábrica Universal
git submodule add https://github.com/Heverton-web/fabrica-universal.git fabrica-universal
git submodule update --init --recursive

# 3. Copiar governança e scripts
cp -r fabrica-universal/.claude .
mkdir -p scripts && cp -r fabrica-universal/scripts/* scripts/

# 4. Criar links e instalar o hook de proteção
powershell .\scripts\setup-links.ps1 meu-projeto   # Linux: bash scripts/setup-links.sh meu-projeto
