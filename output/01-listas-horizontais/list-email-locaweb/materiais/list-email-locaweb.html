01

Mailcow Dockerized

OFICIAL & TESTADO SUBSTITUI: Locaweb Email / cPanel Webmail / Plesk R$ 24.000/ano GPL-3.0 Email Server Suite
1. O Que Faz & Como Funciona

Definição Operacional: Stack containerizado completo: Postfix (SMTP), Dovecot (IMAP/POP3), Nginx (webmail), Roundcube (cliente web), SOGo (calendário/contatos), gerenciamento de usuários, antispam (Rspamd), antivírus (ClamAV), certificados Let's Encrypt, backup automático e failover geo-redundante.

Mecânica Interna & Arquitetura: Docker Compose orquestra 12+ containers. Nginx reverse-proxy expõe webmail, Admin UI para gerenciar domínios/mailboxes, Postfix recebe e roteia mensagens, Dovecot autentica e entrega via IMAP/POP3. Rspamd aprende padrões de spam em tempo real. ClamAV escaneia anexos.

git clone https://github.com/mailcow/mailcow-dockerized.git && cd mailcow-dockerized && ./generate_config.sh && docker-compose up -d
2. Análise Econômica & Impacto Financeiro
SaaS Proprietário Substituído Locaweb Email / cPanel Webmail / Plesk
Economia Declarada & ROI R$ 24.000/ano
3. Requisitos de Infraestrutura & Veredito Técnico
Consumo de Recursos & Hardware 4 GB RAM / 2 vCPU
Por Que é Ouro / Veredito

Padrão-ouro da substituição Locaweb. Stack pronta para produção com segurança certificada (DKIM, SPF, DMARC, TLS), gerenciamento de usuários robusto e suporte ativo da comunidade.

Acessar Repositório Oficial no GitHub (mailcow/mailcow-dockerized)
4. Como Usar no Dia a Dia (Guia Prático)
Passo 01 Deploy em VPS

Clonar repositório, executar generate_config.sh, ajustar DNS records e iniciar com docker-compose up -d.

Passo 02 Configurar Domínios

Acessar painel Admin (porta 80/443), adicionar domínio, criar mailboxes e configurar certificado TLS automático via Let's Encrypt.

Passo 03 Migração de Emails

Usar ferramenta como Imapsync para migrar mensagens de Locaweb, configurar registros MX para apontar ao novo servidor.

5. White-Label & Aderência ao Design System Corporativo
Suite Integrada / UI Incluída Roundcube + SOGo + Admin UI customizável White-Label Nativo
Mecânica de Customização

Roundcube totalmente personalizável via plugins. Logo, cores e domínio do webmail são configuráveis por usuário/domínio.

Impacto em Upgrades & Manutenibilidade

Releases mensais, breaking changes raros. Upgrade via docker-compose pull && docker-compose up -d.

04

Postfix + Dovecot (Config Manual)

OFICIAL & TESTADO SUBSTITUI: Locaweb Email / Sendgrid (SMTP relay) R$ 18.000/ano IPL / MIT MTA/MDA (Manual Setup)
1. O Que Faz & Como Funciona

Definição Operacional: Dupla clássica: Postfix (Mail Transfer Agent) recebe/envia mensagens SMTP, Dovecot (Mail Delivery Agent) autentica usuários e entrega via IMAP/POP3. Requer configuração manual de TLS, DKIM, SPF, DMARC, antispam e backup.

Mecânica Interna & Arquitetura: Instalação via apt-get, configuração de /etc/postfix/ e /etc/dovecot/. Spamd ou Rspamd opcional para antispam. Certificados Let's Encrypt para TLS. Banco de dados (MySQL/PostgreSQL) para gerenciar usuários e domínios.

apt-get install postfix dovecot-core dovecot-imapd dovecot-pop3d && postfix-config
2. Análise Econômica & Impacto Financeiro
SaaS Proprietário Substituído Locaweb Email / Sendgrid (SMTP relay)
Economia Declarada & ROI R$ 18.000/ano
3. Requisitos de Infraestrutura & Veredito Técnico
Consumo de Recursos & Hardware 2 GB RAM / 1 vCPU
Por Que é Ouro / Veredito

Gold standard para sysadmins experientes. Máxima flexibilidade, controle granular, integração profunda com LDAP/Active Directory. Exige expertise e monitoramento ativo.

Acessar Repositório Oficial no GitHub (postfix/postfix (mirror) + dovecot/core)
4. Como Usar no Dia a Dia (Guia Prático)
Passo 01 Instalar Componentes

apt-get install postfix dovecot-{core,imapd,pop3d,mysql} && systemctl enable postfix dovecot

Passo 02 Configurar Postfix

Editar /etc/postfix/main.cf para mydomain, mynetworks, TLS, DKIM. Configurar virtual_mailbox_domains e virtual_mailbox_maps com banco de dados.

Passo 03 Configurar Dovecot

Editar /etc/dovecot/conf.d/10-ssl.conf para TLS, 10-auth.conf para autenticação MySQL, 10-mail.conf para mailbox_location.

5. White-Label & Aderência ao Design System Corporativo
CLI / Sem UI Nativa (requer Roundcube/Rainloop separado) Roundcube ou Rainloop como frontend opcional White-Label Parcial
Mecânica de Customização

Requer integração manual de webmail. TLS, DKIM, SPF configuráveis via texto. Exige SSH acesso.

Impacto em Upgrades & Manutenibilidade

Upgrade manual de pacotes. Monitoramento via Nagios/Prometheus recomendado.
