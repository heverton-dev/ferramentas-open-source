01

Postfix (The Workhorse SMTP/MTA Server)

A Mais Robusta OFICIAL & TESTADO SUBSTITUI: Haraka / SendGrid / AWS SES (SMTP Relay Service) R$ 48.000/ano EPL-2.0 Enterprise-Grade SMTP Mail Transfer Agent
1. O Que Faz & Como Funciona

Definição Operacional: Servidor de correio eletrônico (MTA) mais confiável e estável do planeta: aceita mensagens SMTP, roteia para servidores de destino com retry inteligente, gerencia filas persistentes e implementa políticas de antispam nativas.

Mecânica Interna & Arquitetura: Desenvolvido em C de altíssimo desempenho com arquitetura modular, suporte nativo a SPF/DKIM/DMARC para autenticação, integração com bancos de dados SQL para virtual_mailbox_maps e aliases dinâmicos.

docker run -d --name postfix -v /etc/postfix:/etc/postfix -v /var/spool/postfix:/var/spool/postfix -p 25:25 -p 587:587 boky/postfix:latest
2. Análise Econômica & Impacto Financeiro
SaaS Proprietário Substituído Haraka / SendGrid / AWS SES (SMTP Relay Service)
Economia Declarada & ROI R$ 48.000/ano
3. Requisitos de Infraestrutura & Veredito Técnico
Consumo de Recursos & Hardware 512 MB RAM / 1 vCPU
Por Que é Ouro / Veredito

O padrão ouro indiscutível de servidores SMTP: qualquer empresa pode dispensar SendGrid e rodar seu próprio MTA com total controle de reputação, IP dedicado e zero taxas por email.

Acessar Repositório Oficial no GitHub (postfix/postfix)
4. Como Usar no Dia a Dia (Guia Prático)
Passo 01 Configuração do main.cf

Configure o arquivo main.cf com hostname (mail.suaempresa.com.br), redes de confiança, suporte a SASL para autenticação SMTP e políticas anti-relay.

Passo 02 Setup de DKIM e SPF

Gere chaves DKIM com OpenDKIM, crie registros DNS SPF/DKIM/DMARC para validação de origem e garantir pontuação 10/10 no mail-tester.

Passo 03 Integração com Dovecot ou Mailcow

Combine Postfix com servidor IMAP/POP3 para armazenamento completo de emails e acesso via webmail.

5. White-Label & Aderência ao Design System Corporativo
Baixo Postfixadmin Web / Adminer SQL White-Label Parcial
Mecânica de Customização

Painel Postfixadmin permite gestão visual de domínios, contas e aliases sem edição de arquivos de configuração.

Impacto em Upgrades & Manutenibilidade

Excelente: codebase estável desde 1998, compatibilidade reversa garantida, releases de segurança mantidas por decades.

02

Mailcow: dockerized (Stack Corporativo All-in-One de E-mail)

A Mais Completa OFICIAL & TESTADO SUBSTITUI: Haraka + SendGrid + Google Workspace (Mail Stack Completo) R$ 63.000/ano GPL-3.0 All-in-One Dockerized Mail Suite (SMTP + IMAP + Webmail + Antispam)
1. O Que Faz & Como Funciona

Definição Operacional: Suíte corporativa completa de correio em contêineres Docker: MTA (Postfix), servidor IMAP/POP3 (Dovecot), filtro antispam com IA (Rspamd), antivírus (ClamAV), webmail (SOGo), gerenciamento de domínios via painel web e sincronização CalDAV/CardDAV.

Mecânica Interna & Arquitetura: Orquestração via Docker Compose com MariaDB, Redis para cache/reputação de IP, Let's Encrypt automático para TLS, DKIM por domínio, integração com AD/LDAP para autenticação corporativa.

git clone https://github.com/mailcow/mailcow-dockerized && cd mailcow-dockerized && ./generate_config.sh && docker compose up -d
2. Análise Econômica & Impacto Financeiro
SaaS Proprietário Substituído Haraka + SendGrid + Google Workspace (Mail Stack Completo)
Economia Declarada & ROI R$ 63.000/ano
3. Requisitos de Infraestrutura & Veredito Técnico
Consumo de Recursos & Hardware 4 GB RAM / 2 vCPU
Por Que é Ouro / Veredito

A solução mais completa para empresas que exigem email corporativo autônomo com webmail, calendário, contatos, antispam inteligente e painel administrativo visual — substitui integralmente Google Workspace + Haraka.

Acessar Repositório Oficial no GitHub (mailcow/mailcow-dockerized)
4. Como Usar no Dia a Dia (Guia Prático)
Passo 01 Provisionamento do Stack Docker

Clone o repositório, execute generate_config.sh informando seu hostname (mail.suaempresa.com.br) e levante o stack com docker compose up -d.

Passo 02 Configuração de DNS Corporativo

Copie os registros DNS gerados no painel do Mailcow (MX, SPF, DKIM, DMARC) para sua zona DNS para garantir entregabilidade 10/10.

Passo 03 Criação de Domínios e Caixas Postais

Acesse https://mail.suaempresa.com.br, provisione domínios ilimitados, crie caixas postais com quotas personalizadas e configure regras de filtro Rspamd por usuário.

5. White-Label & Aderência ao Design System Corporativo

Impacto em Upgrades & Manutenibilidade

Script ./update.sh realiza atualização automática preservando volumes de banco e arquivos de email intactos.

Mox (Secure Modern Email Server in Go)

A Mais Moderna OFICIAL & TESTADO SUBSTITUI: Haraka / Postmark (Modern Cloud Email Service) R$ 36.000/ano MIT Modern All-in-One Mail Server (SMTP + IMAP + Webmail)
1. O Que Faz & Como Funciona

Definição Operacional: Servidor de email moderno escrito em Go com filosofia security-first: SMTP/IMAP/Webmail integrados, DKIM/SPF/DMARC nativos, TLS obrigatório, proteção contra phishing, autenticação 2FA e suporte a DANE para certificados DNSSEC.

Mecânica Interna & Arquitetura: Binário único compilado em Go com zero dependências, inicialização automática de certificados ACME, interface web para administração e webmail responsivo, suporte a webhooks para integração com microsserviços.

docker run -d --name mox -v /data:/data -p 25:25 -p 587:587 -p 993:993 -p 80:80 -p 443:443 mjl/mox:latest
2. Análise Econômica & Impacto Financeiro

Acessar Repositório Oficial no GitHub (mjl-/mox)
4. Como Usar no Dia a Dia (Guia Prático)
Passo 01 Inicialização Automática

Execute o binário mox quickstart mail.suaempresa.com.br e ele gera automaticamente configuração, certificados Let's Encrypt e registros DNS necessários.

Passo 02 Setup de DANE (DNSSEC + Certificados)

Configure DNSSEC na sua zona DNS e Mox gerará automaticamente registros TLSA para validação de certificados no destino via DANE (RFC 6698).

Passo 03 Acesso via Webmail ou IMAP

Abra https://mail.suaempresa.com.br para webmail responsivo ou configure cliente Thunderbird/Mail com imap.suaempresa.com.br:993.

OpenSMTPD (Simple & Secure SMTP Server from OpenBSD)

A Mais Simples OFICIAL & TESTADO SUBSTITUI: Haraka (SMTP Gateway Simples) R$ 12.000/ano ISC Minimal & Secure SMTP Server
1. O Que Faz & Como Funciona

Definição Operacional: Servidor SMTP ultrasimples e seguro por padrão do projeto OpenBSD: configuração em sintaxe limpa, sem funcionalidades desnecessárias, focado apenas em aceitar e rotear emails com máxima segurança e performance.

Mecânica Interna & Arquitetura: Desenvolvido em C com auditoria de segurança rigorosa, processo isolado em jail (privilege separation), suporte nativo a TLS 1.3 e autenticação SASL, sintaxe de configuração limpa sem 300 opções.

docker run -d --name opensmtpd -v /etc/opensmtpd:/etc/opensmtpd -p 25:25 -p 587:587 opensmtpd/opensmtpd:latest
2. Análise Econômica & Impacto Financeiro
SaaS Proprietário Substituído Haraka (SMTP Gateway Simples)

A escolha dos puristas: OpenSMTPD implementa o protocolo SMTP com total foco em segurança e simplicidade, eliminando bloat e superficialidade de configuração.

4. Como Usar no Dia a Dia (Guia Prático)
Passo 01 Configuração Limpa

Edite /etc/opensmtpd/smtpd.conf com sintaxe declarativa: listen, route, relay rules em poucas linhas.

Passo 02 Setup de TLS

Configure caminho para certificado privado e pública de Let's Encrypt para suporte a STARTTLS obrigatório.

Passo 03 Teste com SMTP

Envie emails de teste com telnet localhost 25 ou use cliente de email configurando SMTP auth e TLS na porta 587.

5. White-Label & Aderência ao Design System Corporativo

Mecânica de Customização

Configuração puramente textual em sintaxe OpenSMTPD sem interfaces web ou dependências externas.
