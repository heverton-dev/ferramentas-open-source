01

Modoboa (Email Server & Webmail Completo)

A Mais Robusta OFICIAL & TESTADO SUBSTITUI: Modoboa / Google Workspace Email / Microsoft 365 R$ 96.000/ano ISC Full-Stack Mail Server & Webmail Platform
1. O Que Faz & Como Funciona

Definição Operacional: Plataforma completa de email com servidor SMTP/IMAP/POP3 integrado, webmail interativo tipo Gmail, calendário CalDAV, contatos CardDAV, gerenciamento de domínios, filtros Sieve, antispam Rspamd, backup automatizado e autenticação LDAP/OAuth2.

Mecânica Interna & Arquitetura: Desenvolvido em Python/Django com componentes Postfix (MTA), Dovecot (IMAP), ClamAV (antivírus) orquestrados em Docker Compose, interface web responsiva com sincronização bidirecionalmente com clientes desktop (Thunderbird, Outlook) e móvel (IMAP).

git clone https://github.com/modoboa/modoboa.git && cd modoboa && docker-compose up -d

Por Que é Ouro / Veredito

A solução mais robusta e com feature-parity total com Google Workspace e Microsoft 365: você ganha webmail bonito, calendário, contatos, filtros Sieve avançados e controle absoluto sobre reputação de IP de saída de email.

Acessar Repositório Oficial no GitHub (modoboa/modoboa)

Passo 02 Configuração de Domínios e Usuários

Crie domínios e caixas de email através da interface web administrativa com suporte a cotas de armazenamento.

Passo 03 Sincronização com Clientes Desktop

Configure Thunderbird, Outlook ou Evolution para conectar via IMAP/SMTP e manter calendário sincronizado via CalDAV.

02

Apache James (Enterprise Mail Server & Storage)

A Mais Completa OFICIAL & TESTADO SUBSTITUI: Modoboa / Exchange Online / Gmail Enterprise R$ 120.000/ano Apache-2.0 Enterprise-Grade Mail Server & Message Store
1. O Que Faz & Como Funciona

Definição Operacional: Servidor de email corporativo de altíssima performance com suporte a SMTP, IMAP, POP3, ManageSieve, armazenamento distribuído com Cassandra/RabbitMQ, clustering automático, filtros de segurança avançados e conformidade com padrões internacionais.

Mecânica Interna & Arquitetura: Desenvolvido em Java com arquitetura de microsserviços nativa para nuvem, suporte a sharding de mailboxes, redundância de dados, API REST para automação administrativa e integração com Kerberos para autenticação corporativa.

docker run -d -p 25:25 -p 143:143 -p 110:110 --name james apache/james:latest
2. Análise Econômica & Impacto Financeiro
SaaS Proprietário Substituído Modoboa / Exchange Online / Gmail Enterprise
Economia Declarada & ROI R$ 120.000/ano
3. Requisitos de Infraestrutura & Veredito Técnico
Consumo de Recursos & Hardware 4 GB RAM / 4 vCPUs
Por Que é Ouro / Veredito

Escolha dos grandes fornecedores de email corporativo e ISPs: clustering automático, redundância garantida e performance de milhões de mensagens por dia sem degradação.

Acessar Repositório Oficial no GitHub (apache/james-project)
4. Como Usar no Dia a Dia (Guia Prático)
Passo 01 Deployment em Kubernetes

Passo 02 Configuração de Clustering & Replicação

Passo 03 Setup de Filtros de Segurança

Configure SpamAssassin, ClamAV e rate limiting para proteger contra spam e malware em escala.

Mecânica de Customização

Maddy Mail Server (Minimal, Zero-Config Email)

A Mais Leve OFICIAL & TESTADO SUBSTITUI: Modoboa Lightweight / Tutanota / ProtonMail Budget R$ 36.000/ano GPL-3.0 Lightweight Self-Hosted Mail Server
1. O Que Faz & Como Funciona

Definição Operacional: Servidor SMTP/IMAP minimalista porém completo desenvolvido em Go, com zero dependências externas, suporte nativo a DANE/MTA-STS para segurança de email, armazenamento local simples e configuração declarativa YAML.

Mecânica Interna & Arquitetura: Compilado em binário único Go sem Python, Ruby ou dependências pesadas, consome menos de 50 MB de RAM, oferece acesso IMAP puro para integração com Thunderbird/Evolution e suporte a TLS automático via Let's Encrypt.

docker run -d -p 25:25 -p 143:143 -e MADDY_DOMAIN=seu-dominio.com --name maddy foxcpp/maddy:latest
2. Análise Econômica & Impacto Financeiro
SaaS Proprietário Substituído Modoboa Lightweight / Tutanota / ProtonMail Budget
Economia Declarada & ROI R$ 36.000/ano
3. Requisitos de Infraestrutura & Veredito Técnico
Consumo de Recursos & Hardware 256 MB RAM / 0.5 vCPU
Por Que é Ouro / Veredito

Perfeito para pequenas empresas, freelancers e startups que querem um servidor de email próprio sem sobrecarga operacional: instale, configure o DNS uma vez e pronto, email funciona por anos.

Acessar Repositório Oficial no GitHub (foxcpp/maddy)
4. Como Usar no Dia a Dia (Guia Prático)
Passo 01 Execução da Imagem Docker

Inicie Maddy com volume persistente para armazenamento de emails em /var/lib/maddy.

Passo 02 Configuração de Domínio & DNS

Aponte registros MX, SPF, DKIM e DMARC do seu domínio para IP do servidor Maddy.

Passo 03 Conexão de Clients

Configure Thunderbird com SMTP/IMAP apontando para o servidor Maddy (TLS automático via Let's Encrypt).

5. White-Label & Aderência ao Design System Corporativo
Mínimo CLI + YAML Configuration White-Label Parcial
Mecânica de Customização

Configuração 100% YAML sem interface web, extensível via middleware chain.

Impacto em Upgrades & Manutenibilidade

Excelente: uma vez rodando, quase não precisa de atualizações.

MailCatcher (Developer Mock Mail Server)

A Mais Simples OFICIAL & TESTADO SUBSTITUI: Modoboa Development / Mailtrap Free R$ 6.000/ano MIT Simple Mock SMTP Server for Testing
1. O Que Faz & Como Funciona

Definição Operacional: Servidor SMTP e webmail simplificado para captura de emails em ambientes de desenvolvimento e teste, sem necessidade de servidor de email real ou credenciais SMTP.

Mecânica Interna & Arquitetura: Desenvolvido em Ruby com interface web leve que armazena emails em memória ou SQLite, API REST para asserções em testes automatizados e suporte a limpeza de mensagens.

docker run -d -p 1025:1025 -p 1080:1080 --name mailcatcher schickling/mailcatcher
2. Análise Econômica & Impacto Financeiro
SaaS Proprietário Substituído Modoboa Development / Mailtrap Free
Economia Declarada & ROI R$ 6.000/ano
3. Requisitos de Infraestrutura & Veredito Técnico
Consumo de Recursos & Hardware 64 MB RAM / 0.25 vCPU
Por Que é Ouro / Veredito

O servidor SMTP mock preferido dos desenvolvedores Ruby, Python e Node.js: inicia em 1 segundo, captura todos os emails enviados e oferece interface web para inspeção sem risco de disparo acidental.

Acessar Repositório Oficial no GitHub (sj26/mailcatcher)
4. Como Usar no Dia a Dia (Guia Prático)
Passo 01 Execução do Container Docker

Inicie o contêiner expondo porta 1025 (SMTP) e 1080 (Web).

Passo 02 Configuração da Aplicação

Aponte SMTP_HOST=mailcatcher na sua aplicação e veja todos os emails chegarem na web UI.

Passo 03 Leitura de Emails via API REST

Acesse GET /messages para programar asserções em testes E2E e CI/CD.
