Postal · Stalwart · Mailcow

👨‍💻 Nível: Sênior / Especialista Substitui: Soluções Proprietárias Pagas Economia: Economia no TCO MIT / AGPL-3.0 / GPL-3.0 E-mail
1. O Que Faz & Como Funciona

Três servidores de e-mail self-hosted com propósitos diferentes. Postal (MIT) é relay de envio em massa, feito para aplicação — o par natural do Listmonk. Stalwart (AGPL-3.0) é a pilha moderna em Rust, com JMAP e configuração sã. Mailcow (GPL-3.0) é a suíte completa com caixa de entrada, webmail e antispam, para sair do Google Workspace.

Processamento nativo integrado a pipelines e esteiras de automação corporativa.

git clone https://github.com/postalserver/install /opt/postal/install
/opt/postal/install/bin/postal bootstrap postal.seudominio.com

Armadilhas · captação

Oito coisas que trocar de software não resolve

Aqui a armadilha principal não é a licença — é achar que o gargalo era a ferramenta. Metade do que se paga em marketing não é software: é reputação, é índice de dados, é operação.

Entregabilidade não se instala

Reputação de IP

Subir o Postal leva uma tarde; construir reputação de IP leva semanas de aquecimento com SPF, DKIM, DMARC e PTR corretos. IP novo de VPS costuma já nascer em lista de bloqueio. Errar aqui não derruba serviço — manda a campanha inteira para spam em silêncio.

Caminho: relay para SES/Postmark primeiro, IP próprio só depois

Matomo não é Hotjar grátis

Plugins premium

Mapa de calor, gravação de sessão, funis e teste A/B são plugins comerciais sob EULA da InnoCraft. O núcleo GPL substitui o Google Analytics muito bem — mas a parte "vejo o usuário mexendo o mouse" continua paga.

Troca: PostHog (item 19) se replay for essencial

Ahrefs e Semrush não têm substituto

O ativo é o índice

O produto não é o software: é um índice de backlinks e de volume de busca construído com anos de rastreamento. Nenhum projeto livre replica isso, e quem promete faz raspagem que quebra em semanas.

Realidade: Search Console (grátis) para o seu site + Unlighthouse para o técnico

n8n

Sustainable Use License

Continua sendo o nome mais citado em automação e continua não sendo open source. Uso interno liberado; oferecer automação como serviço a cliente, não. Para quem vende automação, isso não é detalhe.

Troca: Activepieces (item 3, MIT) ou Windmill (item 16, AGPL)

RudderStack e OpenReplay

Licença fragmentada

Os dois misturam licenças por diretório e por repositório — Elastic License, AGPL, MIT e enterprise convivendo no mesmo projeto. Não é que sejam proibidos; é que você precisa auditar pasta por pasta para saber o que pode.

Troca: Jitsu (MIT integral) e PostHog com o asterisco declarado

Directus

BSL

Saiu da licença permissiva para Business Source License. Continua ótimo e continua fora do critério — e é citado como "CMS open source" em praticamente toda lista de 2026.

Troca: Strapi (item 18) ou Payload

Prospecção fria com dado raspado

LGPL... digo, LGPD

Coletar e-mail de terceiro para disparo frio esbarra na LGPD, e a base legal de "legítimo interesse" não cobre marketing não solicitado a pessoa física. O software é livre; a lista, não.

Regra: opt-in registrado com data e origem — que é o que o Listmonk e o Keila guardam

Vinte ferramentas, nenhuma operação

Erro de sequência

A tentação desta lista é instalar tudo. Cada item é um serviço para atualizar, um backup a fazer e uma superfície a proteger. Marketing que funciona costuma ser três ferramentas usadas de verdade, não vinte instaladas.

Regra: uma por trimestre, e só quando a anterior já estiver dando número

Método

Como a ordem foi montada

Sem repetir as listas anteriores

Listmonk, Postiz, Umami, Dub, Typebot e Ghost já estão nas listas 1 e 2 e não voltam aqui. Esta ataca o que faltava debaixo deles — a começar pelo servidor que efetivamente entrega o e-mail.

O que destrava o resto vem primeiro

O item 1 não é o mais impressionante, é o que faz o item 2 e a lista 1 funcionarem. Sem servidor de e-mail confiável, automação de jornada é enfeite.

Open core vai marcado

PostHog, Odoo, Matomo, GrowthBook, Activepieces e Strapi têm parte comercial. Está declarado em cada ficha, com o que exatamente fica de cada lado — não escondido atrás de "MIT".

Governança conta como critério

Depois de Cal.com, NocoDB, Directus e MinIO mudarem as regras, projeto sob fundação (Apache Superset) ganha ponto sobre projeto sob empresa com investidor.

Se for adotar duas, no seu caso

Item 1 como relay, não como servidor. Aponte o Postal para o SES e ganhe fila, retentativa e log próprios sem apostar reputação de IP no primeiro dia. Isso resolve o "custo real" que eu registrei no Listmonk lá na lista 1 — e é reversível.

Depois, Windmill (item 16), e não o Activepieces. Você já tem uma pasta scripts/ cheia de Python determinístico; o Windmill transforma cada um em formulário, API e agendamento sem reescrever nada. Para quem já programa, arrastar bloco é mais lento que escrever — e a sua fábrica inteira é a prova disso.
