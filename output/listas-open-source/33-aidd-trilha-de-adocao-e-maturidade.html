Parte 1 · Os 3 Níveis de Adoção

Escolha a esteira certa para a sua escala

Evite o excesso de engenharia. Comece no nível enxuto em 15 minutos e evolua para a soberania total conforme o projeto escala.

Nível 1 · Starter / Enxuto

AIDD Individual de Alta Velocidade

Foco em acelerar o desenvolvedor solo sem atrito de infraestrutura. Empacotamento de contexto compacto (Repomix), copiloto de terminal com diffs cirúrgicos (Aider/Cline) e gateway unificado de modelos (LiteLLM).

Stack Típica: Aider + LiteLLM + Repomix + OpenWebUI
Nível 2 · Intermediário / Squad Ágil

Orquestração, Specs & Qualidade

Foco na esteira de equipe com governança. Criação de contratos de especificação rigorosos (Spec-Kit), subagentes especializados (CrewAI/OpenHands), RAG de código sobre AST (Qdrant + Tree-sitter) e observabilidade de tokens (Langfuse).

Stack Típica: Spec-Kit + CrewAI + Qdrant + Langfuse + Playwright
Nível 3 · Full Sovereign / Enterprise

Autonomia & Soberania Industrial

Foco em zero vazamento de dados, conformidade estrita e infraestrutura proprietária. Motores de inferência de altíssimo throughput locais (vLLM/SGLang), fine-tuning local (Unsloth), verificação formal matemática (Z3) e PaaS self-hosted (Coolify/k3s).

Stack Típica: vLLM + Unsloth + Z3 + ERPNext + Coolify + TRELLIS

Parte 3 · Guia de Implantação Prática

Quickstart determinístico para cada nível

Comandos prontos para configurar o ambiente de desenvolvimento de acordo com a maturidade desejada.

01

Nível 1 · Setup do AIDD Enxuto (15 Minutos)

CUSTO DE INFRAESTRUTURA: R$ 0 / mês Pronto para Uso
1. Passo a Passo de Instalação

Instale o Aider no terminal e configure o Repomix para compactar o repositório antes de enviar contextos pesados.

pip install aider-chat
npm install -g repomix
# Compactar codebase inteira para o prompt:
repomix --output contexto.xml
2. Como Operar no Dia a Dia

Abra o Aider na raiz do projeto: aider --model sonnet. Deixe a IA propor e aplicar diffs atômicos com auto-commit git em cada funcionalidade implementada.

Benefício Imediato
5x mais velocidade de codificação

Veredito: A melhor porta de entrada. Zero overhead de servidores e produtividade instantânea.

02

Nível 2 · Setup do AIDD Intermediário (Squad & Qualidade)

ECONOMIA: -$ 2.400 a $ 6.000 / ano Squad Ágil
1. Passo a Passo de Instalação

Suba o banco vetorial Qdrant e o servidor de observabilidade Langfuse com Docker Compose.

# Subir Qdrant e Langfuse
docker run -d -p 6333:6333 qdrant/qdrant
docker run -d -p 3000:3000 --name langfuse langfuse/langfuse:latest
2. Como Operar no Dia a Dia

Crie arquivos SPEC.md antes de codificar. Os subagentes do CrewAI leem as especificações, consultam a base no Qdrant e reportam métricas de custo no painel do Langfuse.

Benefício Imediato
Zero alucinação & Visibilidade de Custos

Veredito: Essencial para equipes a partir de 2 desenvolvedores que precisam de governança de código.

03

Nível 3 · Setup do AIDD Full Sovereign (Independência Total)

SOBERANIA: 100% On-Premise / Zero Nuvem Enterprise Grade
1. Passo a Passo de Instalação

Execute inferência local de alta performance com vLLM e configure o orquestrador Coolify no seu servidor dedicado.

# Subir servidor vLLM local compatível com API OpenAI:
vllm serve Qwen/Qwen2.5-Coder-32B-Instruct --port 8000 --gpu-memory-utilization 0.95
# Instalar Coolify para PaaS autônoma:
curl -fsSL https://cdn.coolify.io/install.sh | bash
2. Como Operar no Dia a Dia

Todas as requisições de código dos agentes batem no seu servidor vLLM local na porta 8000. Nenhum byte de código confidencial sai da rede privada da empresa.

Benefício Imediato
Conformidade Estrita & Zero Custo de Tokens

Veredito: O ápice da engenharia soberana. Autonomia total sobre modelos, dados e esteira produtiva.

Matriz de Maturidade AIDD auditada pela Fábrica Universal. Todos os modelos e ferramentas estão arquivados e sincronizados na organização oficial.
