01

Skill: impeccable

SUBSTITUI: Interfaces geradas por IA genéricas e feias ECONOMIA: Zero retrabalho de frontend e CSS MIT / Design Skill Design & UI Guardrail Skill
1. O Que Faz

Impõe regras matemáticas de design system: alinhamento estrito, tokens CSS, contraste WCAG AAA, hierarquia tipográfica e scrollbars customizadas.

2. Como Funciona (Mecânica Interna)

Injeta guardrails de design na geração de código frontend: proíbe classes inline aleatórias, exige uso de variáveis CSS padronizadas, dark mode nativo e acabamento editorial refinado.

# Regra: 'Artefatos visuais seguem padrao editorial unico validado por gate de design'
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Ative a skill impeccable no seu agente de frontend.
2. Peça para gerar dashboards, landing pages ou componentes UI.
3. O agente emite código com acabamento profissional, proporção áurea, dark mode automático e scrollbar de 4px.

Especificação & Realidade
0 MB RAM / Guardrail de prompt

Por que é ouro: Elimina a aparência 'cara de template de IA' e gera interfaces prontas para produtos comerciais de alto nível.

github.com/topics/design-system-skills
02

Skill: code-review-graph

SUBSTITUI: Exploração cega de arquivos pelo agente ECONOMIA: -75% de chamadas de exploração de código MIT / Codebase Graph Graph Navigation Skill
1. O Que Faz

Mapeia as dependências, classes, funções e chamadas do repositório em um grafo antes de permitir alterações.

2. Como Funciona (Mecânica Interna)

Lê o índice de símbolos gerado por AST e constrói a árvore de impacto: ao alterar a função A, consulta imediatamente quais módulos B, C e D serão afetados antes de escrever código.

# Regra: 'Consultar code-review-graph antes de tools de leitura/busca'
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. O agente consulta o índice de grafo para saber onde a função é importada.
2. Identifica todos os pontos de quebra antes de editar o primeiro arquivo.
3. Aplica refatorações cirúrgicas com 0 erros de regressão.

Especificação & Realidade
Grafo local em SQLite / < 20 MB

Por que é ouro: Permite ao agente saber exatamente o efeito colateral de qualquer mudança sem precisar ler 50 arquivos.

github.com/code-review-graph
03

Skill: hallmark

SUBSTITUI: Textos com tom de voz inconsistente ECONOMIA: 100% de conformidade editorial MIT / Editorial Skill Brand & Editorial Fidelity
1. O Que Faz

Audita e formata todo o conteúdo de saída de acordo com a voz de marca, rigor terminológico e regras de idioma estritas (PT-BR).

2. Como Funciona (Mecânica Interna)

Valida os artefatos contra uma tabela de termos proibidos (buzzwords vazias, exageros de marketing) e força o uso de precisão técnica e linguagem direta.

# Regra: 'Idioma único e estrito (PT-BR), sem preâmbulos, direto ao ponto'
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Ative a skill hallmark em agentes de documentação e relatórios.
2. Ao gerar artigos, relatórios técnicos ou documentações de API, o texto sai limpo, sem enrolação e com terminologia consistente.
3. Economize tempo de revisão humana de texto.

Especificação & Realidade
0 MB RAM / Regra comportamental

Por que é ouro: Documentação com ruído e palavras vazias reduz a autoridade técnica do projeto. O Hallmark garante tom impecável.

github.com/topics/editorial-standards
04

Skill: mira-animator

SUBSTITUI: Animações pesadas em JavaScript ECONOMIA: 60 FPS nativo e zero bibliotecas extras MIT / Motion Skill Declarative Motion Skill
1. O Que Faz

Gera keyframes e transições em CSS puro e Canvas acelerado por hardware com curvas de bezier naturais.

2. Como Funciona (Mecânica Interna)

Aplica física de amortecimento (spring physics) e aceleração de GPU (transform e opacity) sem importar bibliotecas pesadas de 100KB como Framer Motion.

# Regra: 'Animações fluidas via CSS transforms/opacity nativos com will-change'
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Peça ao agente para criar microinterações para botões, modais e transições de página.
2. A skill gera CSS enxuto com aceleração por hardware.
3. Sua interface roda fluida a 120 FPS em celulares e desktops.

Especificação & Realidade
CSS nativo / 0 overhead JS

Por que é ouro: Animações feitas com CSS nativo e transforms não bloqueiam a thread principal do navegador.

github.com/topics/css-animation
05

Spec-Kit

SUBSTITUI: Desenvolvimento desgovernado por IA ECONOMIA: Economiza semanas de retrabalho em código MIT Spec-Driven Dev
1. O Que Faz

Framework formal do GitHub Next para criar especificações executáveis e validar contratos antes de programar.

2. Como Funciona (Mecânica Interna)

Estrutura o fluxo em três estágios rígidos (SPEC -> PLAN -> TASKS). O agente é impedido de modificar arquivos de implementação até que os arquivos de contrato e a suíte de testes correspondente tenham sido validados.

# SPEC.md -> PLAN.md -> TASKS.md -> EXECUÇÃO
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Crie SPEC.md definindo critérios de aceite e assinaturas de API.
2. O agente gera PLAN.md e quebra em tarefas atômicas.
3. Implementa apenas após a aprovação do plano, testando cada função.

Especificação & Realidade
Documentação formal + testes

Por que é ouro: Garante que a IA nunca comece a gerar arquivos sem saber exatamente o critério de aceite.

github.com/github/spec-kit
06

Aider CLI

SUBSTITUI: Assinatura Cursor ($ 20/mês) ECONOMIA: -$ 240 / ano por desenvolvedor Apache-2.0 Git Pair Programmer
1. O Que Faz

Assistente de linha de comando que opera no repositório Git, resolve issues e gera commits semânticos com árvore AST.

2. Como Funciona (Mecânica Interna)

Constrói um mapa de repositório (repo map) compacto usando Tree-sitter, envia apenas as assinaturas relevantes no prompt e aplica diffs unificados diretamente nos arquivos com validação de linters e testes locais.

pip install aider-chat && aider --model ollama/qwen2.5-coder:7b
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. No terminal do projeto, execute aider src/main.py.
2. Diga: 'Implemente autenticação JWT e adicione testes pytest'.
3. O Aider edita o código, roda os testes locais e faz o commit semântico no Git automaticamente.

Especificação & Realidade
~60 MB RAM

Por que é ouro: Líder mundial consistente no benchmark SWE-bench para resolução de problemas reais de engenharia de software.

aider.chat
07

OpenHands (OpenDevin)

SUBSTITUI: Devin / Magic.dev ($ 500+/mês) ECONOMIA: -$ 6.000 / ano em ferramentas fechadas MIT Autonomous Sandbox
1. O Que Faz

Plataforma de agentes autônomos executados em containers Docker isolados com capacidade de usar browser, terminal e editor.

2. Como Funciona (Mecânica Interna)

Executa um runtime seguro com loop de evento autônomo (Thought -> Action -> Observation). O agente possui acesso a uma VM Linux containerizada onde instala pacotes, roda servidores e depura erros no terminal.

docker run -it -p 3000:3000 ghcr.io/all-hands-ai/openhands:main
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Acesse http://localhost:3000 e conecte seu repositório Git.
2. Atribua uma issue de bug ou refatoração complexa.
3. Acompanhe o agente instalando dependências, rodando testes e abrindo o Pull Request.

Especificação & Realidade
Ambiente Docker isolado

Por que é ouro: O agente instala pacotes e roda testes sem colocar em risco o sistema operacional do desenvolvedor.

all-hands.dev
08

Instructor

SUBSTITUI: Tratamento manual de erros de JSON ECONOMIA: Economiza horas de debugging de parsing MIT Structured Outputs
1. O Que Faz

Biblioteca Python/TS que envelopa chamadas de LLM com validação estrita de modelos Pydantic e retentativas automáticas.

2. Como Funciona (Mecânica Interna)

Envia o schema JSON via Function Calling/Tool Use e valida a resposta no Pydantic. Se ocorrer erro de validação de tipo, reenvia automaticamente apenas o erro de validação para o modelo com instrução de auto-correção.

pip install instructor
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Envolva seu cliente: client = instructor.from_openai(OpenAI()).
2. Defina o schema: class Lead(BaseModel): nome: str, email: str.
3. Chame a API com response_model=Lead e receba objetos Python tipados.

Especificação & Realidade
Zero runtime overhead

Por que é ouro: Se a saída não validar no Pydantic, o Instructor reenvia apenas o erro para a LLM corrigir o campo exato.

python.useinstructor.com
Parte 4 · A Regra de Ouro

Como operar essa pilha com estabilidade

Diretrizes para rodar ferramentas no seu próprio servidor com resiliência máxima e zero sobrecarga.

1. Isolamento em Containers Docker

Nunca instale ferramentas diretamente no sistema host sem isolamento de rede e volumes mapeados em disco seguro.

2. Proxy Reverso com Caddy / Traefik

Aponte a borda de rede para proxies leves com renovação automática de certificados TLS sem scripts manuais.

3. Backup Imutável com Restic / Borg

Programe snapshots diários dos volumes para armazenamento S3 remoto compatível para restauração rápida em caso de desastre.

4. Acesso Seguro via WireGuard / Headscale

Mantenha painéis de administração e bancos de dados fora da internet pública, acessíveis apenas pela VPN mesh interna.
