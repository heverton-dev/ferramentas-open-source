### Scripts de Operação:
- **Descoberta & Ingestão Contínua (Zero Duplicidade):**
  ```bash
  python scripts/descobrir-e-forkear.py
  ```
- **Sincronização Periódica dos Forks (PowerShell):**
  ```powershell
  .\scripts\sync-arsenal.ps1
  ```
- **Sincronização Periódica dos Forks (Bash):**
  ```bash
  bash scripts/sync-arsenal.sh
  ```
- **Gerar / Atualizar Portal Web Interativo:**
  ```bash
  python scripts/gerar-index-organizacao.py
  ```
