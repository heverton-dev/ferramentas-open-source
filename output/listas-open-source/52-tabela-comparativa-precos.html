Detalhamento por SaaS

01 · Notion → AppFlowy / Outline

SaaS: R$ 360/mes (10u) OSS: R$ 0 licenca Infra: ~R$ 50/mes

Planos SaaS

  • Free: 1.000 blocos, 5MB upload
  • Plus: R$ 36/usuario/mes — blocos ilimitados
  • Business: R$ 72/usuario/mes — SAML, avancado
  • Enterprise: preco sob consulta

Alternativas OSS

  • AppFlowy: Desktop nativo, offline-first, Rust+Flutter
  • Outline: Wiki corporativa, RBAC, Slack integration
  • SiYuan: Knowledge graph, block-level ref, Markdown

02 · Google Meet → Jitsi Meet

SaaS: R$ 300/mes (10u) OSS: R$ 0 licenca Infra: ~R$ 60/mes

Planos SaaS

  • Workspace Starter: R$ 28/usuario/mes (inclui Meet)
  • Workspace Plus: R$ 36/usuario/mes (gravacao)
  • Meet Alone: incluido no plano Google

Alternativas OSS

  • Jitsi Meet: WebRTC, ate 100 participantes
  • E2EE, gravacao, compartilhamento de tela
  • API para integracao customizada

04 · ChatGPT Plus → Open WebUI + Ollama

SaaS: R$ 100/mes OSS: R$ 0 licenca Infra: R$ 0 (local)

Planos SaaS

  • Free: GPT-3.5, limites baixos
  • Plus: R$ 100/mes — GPT-4o, DALL-E, Code Interpreter
  • Pro: R$ 725/mes — sem limite, modelos avancados
  • Team: R$ 127/usuario/mes — admin, compartilhamento

Alternativas OSS

  • Ollama: Llama 3.1, Mistral, Phi-3, Gemma, Qwen
  • Open WebUI: Interface tipo ChatGPT, RAG, historico
  • LocalAI: API compativel OpenAI, multi-modelo
  • Custo: GPU 8GB (R$ 2.500 una vez) ou CPU lento

05 · Claude Code → Aider

SaaS: R$ 100/mes OSS: R$ 0 licenca Infra: ~R$ 30/mes (API)

Planos SaaS

  • Pro: R$ 100/mes — Claude Sonnet/Opus
  • Max 5x: R$ 363/mes — limite 5x maior
  • Max 20x: R$ 725/mes — limite 20x maior

Alternativas OSS

  • Aider: Pair programming terminal, multi-arquivo
  • Continue: Extensao VS Code, autocomplete + chat
  • Conecta a qualquer LLM (Claude API, GPT-4o, local)
  • Custo: API Claude ~R$ 30/mes com uso moderado

12 · Zapier → N8N

SaaS: R$ 300/mes OSS: R$ 0 licenca Infra: ~R$ 40/mes

  • Free: 100 tasks/mes, 5 zaps
  • Starter: R$ 127/mes — 750 tasks, 20 zaps
  • Professional: R$ 300/mes — 2.000 tasks, ilimitado

15 · Datadog → Grafana

SaaS: R$ 575/mes (5 hosts) OSS: R$ 0 licenca Infra: ~R$ 60/mes

Planos SaaS

  • Pro: US$ 15/host/mes — metrics, logs, traces
  • Enterprise: US$ 23/host/mes — APM avancado
  • 5 hosts = US$ 115/mes = ~R$ 575/mes

Alternativas OSS

19 · Salesforce → Twenty CRM

SaaS: R$ 750/mes (5u) OSS: R$ 0 licenca Infra: ~R$ 60/mes

Planos SaaS

  • Starter: R$ 150/usuario/mes — basico
  • Professional: R$ 300/usuario/mes — automacao
  • Enterprise: R$ 450/usuario/mes — API avancada
  • 5 usuarios Pro = R$ 1.500/mes

Alternativas OSS

  • Twenty CRM: Interface moderna, GraphQL API
  • ERPNext CRM: Integrado ao ERP, fiscal BR
  • Huly: CRM + projetos em uma plataforma
  • Sem limite de usuarios ou contactos

Riscos & Consideracoes de Custo

  • Infraestrutura compartilhada: O custo de infra (VPS) e dividido entre todas as ferramentas self-hosted. Uma unica VPS de R$ 100/mes pode rodar 5-6 ferramentas.
  • GPU para IA: Modelos locais (Ollama, Bark) exigem investimento inicial em GPU (R$ 2.500-5.000). Amortizado em 1-2 anos vs assinatura.
  • APIs de IA nao sao gratuitas: Aider e Continue precisam de API key (Claude, GPT). O custo depende do uso — geralmente 30-50% da assinatura equivalente.
  • Custo de tempo de setup: Self-hosted requer tempo inicial para configurar. Estime 2-4 horas por ferramenta para setup basico.
  • Manutencao continua: Updates de seguranca, backups, monitoramento. Estime 2-4 horas/mes para manutencao de todas as ferramentas.
  • Ferramentas gratuitas do SaaS: NotebookLM e Google Analytics sao gratuitos (mas coletam dados). A alternativa OSS paga custo de infra mas garante privacidade.
  • Escalonamento: SaaS escala automaticamente. Self-hosted requer dimensionamento manual ao crescer.
