Parte 1 · A Filosofia da Engenharia Agêntica

Por que 90% das pessoas queimam dinheiro com IA e produzem código ruim?

Programar com IA não é sobre abrir uma janela de chat e digitar "crie um app para mim". Engenharia de IA de verdade trata o modelo como uma CPU probabilística dentro de um harness rígido e determinístico.

Pilar I · Spec-Driven & Contexto Cirúrgico

Especificação antes do código

A alucinação nasce da ambiguidade. Usando Spec-Driven Development (Spec-Kit, BMAD) e geradores de contexto comprimido (Repomix, ast-grep), o modelo recebe apenas os 2KB exatos de informação necessária, eliminando retrabalho e faturas infladas.

Pilar II · Ferramentas Conectadas (MCP) & Memória

O poder do Model Context Protocol

Em vez de copiar e colar código manualmente, servidores MCP expõem bancos de dados, árvores sintáticas (AST), navegadores reais e terminais para os agentes agirem com feedback imediato e auto-correção mecânica.

A esteira recomendada de engenharia agêntica

Como combinar essas 25 ferramentas em um processo diário eficiente e sem desperdício de tokens.

1. Extração & Empacotamento

Use Repomix ou Gitingest com filtros estritos para selecionar apenas os arquivos essenciais. Nunca envie o repositório inteiro sem limpeza prévia.

2. Especificação & Contratos

Defina o escopo com Spec-Kit / BMad Method. Descreva as entradas, saídas esperadas e testes em Markdown antes de escrever qualquer código.

3. Pair Programming via Terminal

Rode Aider CLI ou ast-grep com modelo local no Ollama para refatorações cirúrgicas com commits automáticos e rastreamento no Git.

4. Validação & Feedback MCP

Deixe o Chrome DevTools MCP e os scripts de teste (Just / pytest) validarem a execução mecânica com saída `exit 0/1` antes de finalizar a tarefa.
