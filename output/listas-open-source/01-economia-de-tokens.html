01

Skill: caveman

SUBSTITUI: Pensamentos CoT prolixos e caros ECONOMIA: -90% de tokens no bloco MIT / Prompt Skill Agentic Reasoning Compression
1. O Que Faz

Força o agente a pensar em estilo telegráfico (estilo homem das cavernas), sem artigos, sem saudações e sem repetir o prompt do usuário.

2. Como Funciona (Mecânica Interna)

Instrui o modelo a usar frases curtas de 3 a 5 linhas no Chain-of-Thought (ex: 'usr quer X. ler arq Y. corrigir Z.'), economizando até 800 tokens a cada turno de raciocínio interno.

# Ativação via SKILL.md ou regra de sistema: 'Para raciocínios internos, use estilo CAVEMAN telegráfico'
Especificação & Realidade
0 MB RAM / Overhead zero

Por que é ouro: Tokens de pensamento interno custam o mesmo que tokens de saída. Pensar de forma enxuta é a forma mais rápida de economizar.

github.com/topics/claude-skills
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Adicione a skill caveman no diretório .claude/skills/ ou nas regras do seu agente.
2. Ao receber uma instrução, o agente pensa diretamente na solução sem floreios verbais.
3. Reduza a latência de resposta em 60% e economize milhares de tokens por sessão de pareamento.

02

Skill: headroom

SUBSTITUI: Dumps gigantes de terminal no contexto ECONOMIA: -80% de tokens em logs de compilação MIT / Prompt Skill Log & Terminal Compression
1. O Que Faz

Monitora e trunca logs longos de compilação, testes e builds, mantendo apenas o topo do comando e o stack trace do erro.

2. Como Funciona (Mecânica Interna)

Aplica regra rígida: se a saída do comando tiver > 7 linhas, comprime em (3 linhas do topo + 4 linhas do final), preservando a causa raiz da falha sem poluir a janela de contexto.

# Regra: 'Logs > 7 linhas -> comprimir (3 topo + 4 fim)'
Especificação & Realidade
0 MB RAM / Filtro em runtime

Por que é ouro: A maioria dos erros de compilação tem sua causa nas últimas 4 linhas. Ler 300 linhas de warning é queimar dinheiro.

github.com/topics/agentic-skills
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Integre no prompt do seu orquestrador ou hook de execução de comandos.
2. Quando um npm run build falhar com 300 linhas de warnings, o agente só recebe as linhas essenciais do erro.
3. Evita estourar a janela de contexto com logs repetitivos.

03

Skill: lean-ctx

SUBSTITUI: view_file() do arquivo inteiro ECONOMIA: -85% de tokens de leitura de código MIT / Prompt Skill Targeted Code Inspection
1. O Que Faz

Obriga o agente a usar `grep_search` e ler trechos específicos com intervalo de linhas em vez de ler o arquivo completo.

2. Como Funciona (Mecânica Interna)

Impõe restrição comportamental: antes de ler qualquer arquivo com mais de 50 linhas, o agente deve localizar o símbolo exato via grep ou AST e ler apenas a fatia StartLine/EndLine.

# Regra: 'Grep antes de read. Limitar leitura por intervalo estrito de linhas'
Especificação & Realidade
0 MB RAM / Disciplina de agente

Por que é ouro: A maior causa de esquecimento em conversas longas é a poluição do contexto com arquivos lidos integralmente sem necessidade.

github.com/topics/context-engineering
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Ao pedir para o agente alterar uma função em um arquivo de 1.500 linhas, ele faz grep_search pelo nome da função.
2. Em seguida, faz view_file(StartLine=120, EndLine=145).
3. Lê 25 linhas em vez de 1.500 linhas, mantendo o contexto limpo para raciocínios complexos.

04

Skill: rtk-memory

SUBSTITUI: Reenvio de histórico antigo no prompt ECONOMIA: 100% de reuso de prefix cache da Anthropic/OpenAI MIT / Scratchpad Skill Persistent Prefix Cache Memory
1. O Que Faz

Persiste novos aprendizados e correções em um arquivo externo (RTK-SCRATCHPAD.md) para manter as instruções base imutáveis.

2. Como Funciona (Mecânica Interna)

Mantém o arquivo de governança principal (AGENTS.md / CLAUDE.md) intacto para que os provedores de LLM façam cache do prompt de sistema. Novos aprendizados da sessão são appendados em arquivo separado consultado sob demanda.

# Regra: 'Novos aprendizados: SEMPRE appendar em RTK-SCRATCHPAD.md'
Especificação & Realidade
Arquivo Markdown local / 0 RAM

Por que é ouro: Modificar o system prompt invalida o cache de prefixo em provedores como Anthropic, encarecendo todas as chamadas seguintes.

github.com/topics/prompt-caching
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Quando o agente cometer um erro e for corrigido, ele grava a regra aprendida no final do RTK-SCRATCHPAD.md.
2. Em sessões futuras, consulta o scratchpad apenas quando o tema exigir.
3. Mantém o cache de prefixo do seu system prompt 100% aquecido e barato.

05

Repomix

SUBSTITUI: Leitura manual de múltiplos arquivos ECONOMIA: -70% de tokens por prompt (~$ 300/mês) MIT Context Packing
1. O Que Faz

Empacota repositórios inteiros em 1 arquivo XML/Markdown com contagem exata de tokens e filtros inteligentes de .gitignore.

2. Como Funciona (Mecânica Interna)

Varre o repositório, descarta binários, lockfiles e arquivos ignorados no Git e compila um documento único com cabeçalhos XML e numeração de linhas para leitura otimizada por LLMs.

npx repomix --style xml --output-show-line-numbers
Especificação & Realidade
< 30 MB RAM / CLI sob demanda

Por que é ouro: Remove automaticamente arquivos binários, lockfiles e assets pesados antes de enviar o contexto à LLM.

github.com/yamadashy/repomix
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Antes de iniciar uma feature complexa, execute: npx repomix --include 'src/**/*.ts'.
2. O arquivo repomix-output.xml reúne a arquitetura com contagem de tokens no topo.
3. Cole no chat da IA ou anexe no agente para compreensão completa da base.

06

ast-grep (sg)

SUBSTITUI: Refatorações caras via LLM ECONOMIA: 100% grátis em transformações estruturais MIT AST Search & Rewrite
1. O Que Faz

Busca e reescrita de código baseada na Árvore de Sintaxe Abstrata. Não erra espaçamentos nem quebras de linha.

2. Como Funciona (Mecânica Interna)

Faz o parsing do código-fonte em nós de Árvore Sintática (AST) usando Tree-sitter em Rust, permitindo buscar e substituir estruturas com wildcards sintáticos ($$$ARGS) em microssegundos.

cargo install ast-grep && sg --pattern 'function $NAME($$$ARGS) { $$$BODY }'
Especificação & Realidade
Binário Rust / < 10 MB RAM

Por que é ouro: Substitui prompts inteiros de 'renomeie/altere assinatura' por uma chamada determinística de 2ms no terminal.

ast-grep.github.io
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Para alterar a assinatura de uma função em 50 arquivos, rode: sg -p 'api.get($URL)' -r 'api.fetch({url: $URL})' -w.
2. A substituição ocorre em 2ms em todo o repositório.
3. Economize 100% dos tokens que seriam gastos pedindo para uma IA reescrever arquivo por arquivo.

07

LiteLLM Semantic Cache / OmniRouter

SUBSTITUI: Chamadas duplicadas em APIs de LLM ECONOMIA: -40% a -60% na fatura de API (~$ 500/mês) MIT AI Gateway & Cache
1. O Que Faz

Gateway de roteamento inteligente e cache semântico de respostas de LLM em Redis com balanceamento de carga.

2. Como Funciona (Mecânica Interna)

Calcula embeddings de prompts recebidos e faz busca por similaridade de cosseno no Redis antes de disparar requisições para a OpenAI/Anthropic. Se similaridade > 0.95, devolve a resposta cacheada em 2ms.

docker run -d -p 4000:4000 ghcr.io/berriai/litellm:main-latest
Especificação & Realidade
~70 MB RAM em repouso

Por que é ouro: Essencial para suítes de testes de software e pipelines de CI/CD que rodam os mesmos prompts repetidamente.

litellm.ai
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Suba o LiteLLM apontando para seu Redis no arquivo config.yaml.
2. Troque a base URL das suas aplicações e scripts para http://localhost:4000.
3. Suítes de testes automatizados e perguntas repetidas de usuários respondem em 2ms com custo $ 0.

08

DSPy (Stanford)

SUBSTITUI: Engenharia de prompt manual cara ECONOMIA: Reduz tamanho de prompt em até 50% MIT Prompt Compiler
1. O Que Faz

Compila e otimiza automaticamente instruções e few-shots via algoritmos matemáticos para máxima acurácia no menor prompt.

2. Como Funciona (Mecânica Interna)

Modela o pipeline como grafo computacional diferenciável. Otimizadores como BootstrapFewShot testam permutações de prompts contra uma métrica e geram a versão mais enxuta e assertiva.

pip install dspy-ai
Especificação & Realidade
Biblioteca pura / Zero runtime RAM

Por que é ouro: Trata prompts como código compilável. Se você mudar de modelo, basta recompilar o pipeline sem reescrever nada.

dspy.ai
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Defina sua classe de extração: class Extrator(dspy.Module): ....
2. Forneça 10 a 20 exemplos de treino validados.
3. Execute o compilador do DSPy: ele gera automaticamente o prompt mais eficiente e curto para produção.

Parte 4 · A Regra de Ouro

Como operar essa pilha com estabilidade

Diretrizes para rodar ferramentas no seu próprio servidor com resiliência máxima e zero sobrecarga.

1. Isolamento em Containers Docker

Nunca instale ferramentas diretamente no sistema host sem isolamento de rede e volumes mapeados em disco seguro.

2. Proxy Reverso com Caddy / Traefik

Aponte a borda de rede para proxies leves com renovação automática de certificados TLS sem scripts manuais.

3. Backup Imutável com Restic / Borg

Programe snapshots diários dos volumes para armazenamento S3 remoto compatível para restauração rápida em caso de desastre.

4. Acesso Seguro via WireGuard / Headscale

Mantenha painéis de administração e bancos de dados fora da internet pública, acessíveis apenas pela VPN mesh interna.
