01

Caveman · Compressão de Raciocínio CoT em Agentes

Substitui: Pensamentos CoT prolixos e caros Economia: -90% em <thought> MIT / Prompt Skill Reasoning Compression
1. O Que Faz

Força o agente a pensar em estilo telegráfico (homem das cavernas), sem artigos, sem saudações e sem repetir o prompt do usuário.

2. Como Funciona

Instrui o modelo a usar frases curtas de 3 a 5 linhas no Chain-of-Thought (ex: 'usr quer X. ler arq Y. corrigir Z.'), economizando até 800 tokens a cada turno de raciocínio interno.

# Ativação via SKILL.md ou regra de sistema:
'Para raciocínios internos, use estilo CAVEMAN telegráfico'
Especificações
0 MB RAM · Zero Overhead

Por que é ouro: Tokens de pensamento interno custam o mesmo que tokens de saída. Pensar de forma enxuta é a forma mais rápida de economizar.

github.com/topics/claude-skills ↗
3. Como Usar no Dia a Dia (Passo a Passo Prático)
1 Configuração

Adicione a skill caveman no diretório .claude/skills/ ou no arquivo de regras do agente.

2 Execução

Ao receber uma instrução, o agente pensa diretamente na solução técnica sem saudações ou repetição.

3 Resultado

Reduza a latência de resposta em 60% e economize até 90% dos tokens internos por turno de conversa.

02

Headroom · Compressão Inteligente de Logs de Terminal

Substitui: Dumps gigantes de terminal Economia: -80% em logs MIT / Prompt Skill Log & Terminal Compression
1. O Que Faz

Monitora e trunca saídas longas de compilação, testes e builds, mantendo apenas o cabeçalho do comando e o stack trace do erro.

2. Como Funciona

Se a saída do comando tiver > 7 linhas, comprime em (3 linhas do topo + 4 linhas do final), preservando a causa raiz da falha sem poluir a janela de contexto.

# Regra de compressão de saída:
'Logs > 7 linhas -> comprimir (3 topo + 4 fim)'
Especificações
0 MB RAM · Filtro em Runtime

Por que é ouro: A causa do erro está quase sempre nas últimas linhas. Ler 300 linhas de warnings é queimar orçamento à toa.

github.com/topics/agentic-skills ↗
3. Como Usar no Dia a Dia (Passo a Passo Prático)
1 Integração

Declare a regra headroom nas instruções de execução de comandos do seu assistente.

2 Captura

Quando um comando como npm run build falha com 500 linhas, o agente recebe apenas a fatia do erro.

3 Resolução

O agente foca na causa exata sem estourar o limite de tokens da sessão com ruído desnecessário.

03

Lean-CTX · Inspeção Cirúrgica de Código com Grep Prévio

Substitui: view_file() integral Economia: -85% de leitura MIT / Prompt Skill Targeted Code Inspection
1. O Que Faz

Obriga o agente a usar grep_search e ler fatias estritas com intervalo de linhas em vez de carregar arquivos completos.

2. Como Funciona

Antes de ler arquivos com mais de 50 linhas, o agente localiza o símbolo exato e lê apenas a janela necessária (StartLine/EndLine).

# Protocolo Lean-CTX:
'Grep antes de read. Limitar leitura por intervalo estrito de linhas'
Especificações
0 MB RAM · Disciplina Agêntica

Por que é ouro: A principal causa de alucinação em sessões longas é a poluição do contexto por arquivos inteiros lidos sem necessidade.

github.com/topics/context-engineering ↗
3. Como Usar no Dia a Dia (Passo a Passo Prático)
1 Localização

Ao solicitar a edição de uma função em um arquivo de 1.500 linhas, o agente executa grep_search pelo nome exato.

2 Leitura Seletiva

Faz a leitura de apenas 20 linhas ao redor do trecho com view_file(StartLine=120, EndLine=140).

3 Economia

Economiza mais de 1.400 linhas de contexto, mantendo a atenção do modelo afiada para o raciocínio central.

04

RTK-Memory · Memória Scratchpad com Prefix Cache Imutável

Substitui: Reenvio de histórico no prompt Economia: 100% Prefix Cache MIT / Scratchpad Skill Persistent Prefix Cache
1. O Que Faz

Persiste aprendizados e correções em arquivo externo (RTK-SCRATCHPAD.md) para manter as instruções base 100% imutáveis e cacheadas.

2. Como Funciona

Mantém o AGENTS.md fixo para que Anthropic/OpenAI façam reuso do cache de prefixo (desconto de até 90% no input). Aprendizados novos são appendados sob demanda.

# Protocolo RTK:
'Novos aprendizados: SEMPRE appendar em RTK-SCRATCHPAD.md'
Especificações
Markdown Local · Zero RAM

Por que é ouro: Editar o system prompt invalida o cache de prefixo, encarecendo todas as chamadas seguintes do projeto.

github.com/topics/prompt-caching ↗
3. Como Usar no Dia a Dia (Passo a Passo Prático)
1 Registro

Quando o agente aprende uma preferência ou resolve um bug sutil, registra a nota no final do RTK-SCRATCHPAD.md.

2 Consulta

Em tarefas subsequentes, o agente consulta o scratchpad apenas quando o tópico exigir contexto passado.

3 Aquecimento

Garante que o prefix cache do system prompt continue 100% aquecido com custo mínimo de tokens de entrada.

Repomix · Compactador Universal de Código para Contexto de LLMs

Substitui: Leitura manual de arquivos Economia: -70% por prompt (~$ 300/mês) MIT Context Packing
1. O Que Faz

Empacota repositórios inteiros em 1 arquivo XML/Markdown com contagem exata de tokens e filtros inteligentes de .gitignore.

2. Como Funciona

Descarta binários, lockfiles e arquivos ignorados no Git e compila um documento único estruturado com tags XML e numeração de linhas para leitura otimizada por IAs.

npx repomix --style xml --output-show-line-numbers
Especificações
< 30 MB RAM · CLI Sob Demanda

Por que é ouro: Remove automaticamente ruídos pesados (node_modules, build artifacts) antes de transferir contexto para a LLM.

github.com/yamadashy/repomix ↗
3. Como Usar no Dia a Dia (Passo a Passo Prático)
1 Empacotamento

Antes de uma tarefa complexa de arquitetura, rode: npx repomix --include 'src/**/*.ts'.

2 Auditoria

Verifique a contagem exata de tokens gerada no cabeçalho do arquivo repomix-output.xml.

3 Utilização

Forneça o arquivo como anexo no chat ou no contexto inicial do assistente para visão global instantânea.

06

ast-grep (sg) · Busca e Reescrita Estrutural na AST

Substitui: Refatorações caras via LLM Economia: 100% Grátis em Transformações MIT AST Search & Rewrite
1. O Que Faz

Busca e reescrita de código baseada na Árvore de Sintaxe Abstrata (AST). Não erra indentação nem quebra sintaxe.

2. Como Funciona

Faz o parsing do código-fonte em nós sintáticos via Tree-sitter em Rust, permitindo substituir estruturas complexas com curingas ($$$ARGS) em 2ms.

sg --pattern 'function $NAME($$$ARGS) { $$$BODY }'
Especificações
Binário Rust · < 10 MB RAM

Por que é ouro: Substitui prompts caros de 'renomeie / refatore assinatura' por uma execução determinística de microssegundos no terminal.

ast-grep.github.io ↗
3. Como Usar no Dia a Dia (Passo a Passo Prático)
1 Padrão

Defina a transformação: sg -p 'api.get($URL)' -r 'api.fetch({url: $URL})' -w.

2 Aplicação

O sg aplica a reescrita estrutural em dezenas de arquivos em 2ms com precisão cirúrgica.

3 Economia

Zero tokens consumidos para refatorações repetitivas em lote em todo o codebase.

LiteLLM Semantic Cache · Gateway Inteligente com Cache Semântico

Substitui: Chamadas duplicadas em APIs Economia: -40% a -60% na fatura (~$ 500/mês) MIT AI Gateway & Cache
1. O Que Faz

Gateway de roteamento inteligente e cache semântico de respostas de LLM em Redis com balanceamento de carga.

2. Como Funciona

Calcula embeddings de prompts e faz busca por similaridade de cosseno no Redis. Se a similaridade for > 0.95, devolve o resultado cacheado em 2ms com custo $ 0.

docker run -d -p 4000:4000 ghcr.io/berriai/litellm:main-latest
Especificações
~70 MB RAM em Repouso

Por que é ouro: Essencial para suítes de testes automatizados e pipelines de CI/CD que rodam os mesmos prompts repetidamente.

litellm.ai ↗
3. Como Usar no Dia a Dia (Passo a Passo Prático)
1 Inicialização

Inicie o LiteLLM apontando para seu Redis local no arquivo config.yaml.

2 Redirecionamento

Aponte a BASE_URL dos seus apps e agentes para http://localhost:4000.

3 Custo Zero

Suítes de testes automatizados e queries frequentes respondem em 2ms com custo $ 0.
