01

Repomix

SUBSTITUI: Leitura manual de arquivos ECONOMIA: -70% de tokens por prompt (~$ 300/mês) MIT Context Packing
1. O Que Faz

Empacota repositórios inteiros em 1 arquivo XML/Markdown com contagem de tokens e filtros inteligentes de .gitignore.

2. Como Funciona (Mecânica Interna)

Lê a árvore de arquivos, descarta binários, lockfiles e imagens automaticamente via .gitignore e gera um arquivo único com tags XML estruturadas e numeração de linhas para leitura ótima da LLM.

npx repomix --style xml --output-show-line-numbers
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Antes de pedir uma refatoração grande, rode no terminal: npx repomix --include 'src/**/*.ts'.
2. Abra o arquivo repomix-output.xml gerado e verifique a contagem de tokens no topo.
3. Cole no chat da LLM ou use como anexo no seu agente agêntico. A IA responderá com precisão cirúrgica de linha.

Especificação & Realidade
< 30 MB RAM / CLI sob demanda

Por que é ouro: Remove automaticamente arquivos binários, lockfiles e assets pesados antes de enviar o contexto à LLM.

github.com/yamadashy/repomix
02

ast-grep (sg)

SUBSTITUI: Refatorações caras via LLM ECONOMIA: 100% grátis em transformações estruturais MIT AST Search & Rewrite
1. O Que Faz

Busca e reescrita de código baseada na Árvore de Sintaxe Abstrata. Não erra espaçamentos nem quebras de linha.

2. Como Funciona (Mecânica Interna)

Faz o parsing do código-fonte em nós de Árvore Sintática (AST) usando Tree-sitter em Rust, permitindo buscar estruturas com wildcards ($$$ARGS) sem depender de regex frágil.

cargo install ast-grep && sg --pattern 'function $NAME($$$ARGS) { $$$BODY }'
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Para alterar a assinatura de uma função em 40 arquivos, crie o padrão no terminal: sg -p 'api.get($URL)' -r 'api.request({url: $URL, method: "GET"})' -w.
2. Pressione Enter: a alteração ocorre em 3 milissegundos em toda a base.
3. Economize 100% dos tokens que seriam gastos pedindo à IA para editar arquivo por arquivo.

Especificação & Realidade
Binário Rust / < 10 MB RAM

Por que é ouro: Substitui prompts inteiros de 'renomeie/altere assinatura' por uma chamada determinística de 2ms no terminal.

ast-grep.github.io
03

LiteLLM Semantic Cache

SUBSTITUI: Chamadas duplicadas em APIs de LLM ECONOMIA: -40% a -60% na fatura de API (~$ 500/mês) MIT AI Gateway & Cache
1. O Que Faz

Cache semântico de respostas de LLM em Redis. Se o prompt for semanticamente equivalente, responde em 2ms por $ 0.

2. Como Funciona (Mecânica Interna)

Gera um embedding do prompt de entrada e faz uma busca por similaridade de cosseno em um Redis vetorial antes de chamar a API da OpenAI/Anthropic. Se encontrar match > 0.95, devolve o resultado cacheado.

docker run -d -p 4000:4000 ghcr.io/berriai/litellm:main-latest
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Inicie o container LiteLLM apontando para seu Redis no arquivo config.yaml.
2. Na sua aplicação, troque a URL base da OpenAI para http://localhost:4000.
3. Quando suítes de testes ou usuários repetirem perguntas similares, a resposta é entregue em 2ms sem custo de API.

Especificação & Realidade
~70 MB RAM em repouso

Por que é ouro: Essencial para suítes de testes de software e pipelines de CI/CD que rodam os mesmos prompts repetidamente.

litellm.ai
04

DSPy (Stanford)

SUBSTITUI: Engenharia de prompt manual cara ECONOMIA: Reduz tamanho de prompt em até 50% MIT Prompt Compiler
1. O Que Faz

Otimiza automaticamente instruções e few-shots via algoritmos matemáticos para obter a máxima acurácia no menor prompt possível.

2. Como Funciona (Mecânica Interna)

Trata pipelines de IA como grafos de computação diferenciáveis. Otimizadores como BootstrapFewShotWithRandomSearch testam variações de prompts e selecionam os exemplos mais compactos que maximizam a pontuação métrica.

pip install dspy-ai
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Defina sua classe de RAG: class RAG(dspy.Module): ... com assinaturas de entrada e saída.
2. Forneça 15 exemplos de perguntas e respostas corretas.
3. Execute o compilador do DSPy: ele testará combinações e gerará um prompt enxuto e hiper-eficiente para produção.

Especificação & Realidade
Biblioteca pura / Zero runtime RAM

Por que é ouro: Trata prompts como código compilável. Se você mudar de modelo, basta recompilar o pipeline sem reescrever nada.

dspy.ai
05

Outlines / Guidance

SUBSTITUI: Retentativas por JSON quebrado ECONOMIA: Elimina 100% dos tokens de retry por falha de parsing Apache-2.0 / MIT Structured Generation
1. O Que Faz

Força o modelo a seguir gramáticas formais (CFG / Regex / Pydantic) a nível de logits durante a amostragem de tokens.

2. Como Funciona (Mecânica Interna)

Constrói um Autômato Finito Determinístico (DFA) a partir do seu schema JSON. A cada token gerado, mascara os logits para que o modelo só possa escolher caracteres permitidos pela gramática.

pip install outlines
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Crie seu modelo Pydantic: class Pedido(BaseModel): item: str, qtd: int.
2. Instancie o gerador: gerador = outlines.generate.json(modelo, Pedido).
3. Chame resultado = gerador(prompt): o JSON resultante é matematicamente perfeito na primeira tentativa.

Especificação & Realidade
Execução local / overhead < 5ms

Por que é ouro: O modelo é matematicamente incapaz de gerar um caractere fora do schema especificado.

github.com/outlines-dev/outlines
06

Gitingest

SUBSTITUI: Clonagem + extração manual ECONOMIA: Economia de tempo de análise em 90% MIT Web Repo Parser
1. O Que Faz

Converte qualquer repositório público do GitHub em um texto limpo e resumido com contagem exata de tokens para colar em chats.

2. Como Funciona (Mecânica Interna)

Faz o parse da API do GitHub ou clone raso em memória, processa a estrutura de arquivos e cospe um prompt formatado com árvore de diretórios e código limpo.

docker run -d -p 8000:8000 cyclotruc/gitingest
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Ao estudar uma biblioteca nova, troque github.com/dono/repo na barra de endereços por gitingest.com/dono/repo.
2. Escolha o tamanho máximo de arquivo (ex: até 50KB).
3. Clique em 'Copy Context' e cole no seu chat de IA para fazer perguntas sobre o repositório.

Especificação & Realidade
~60 MB RAM

Por que é ouro: Troque 'github.com' por 'gitingest.com' na URL e obtenha o contexto estruturado em 1 segundo.

gitingest.com
07

Tree-sitter CLI

SUBSTITUI: Leitura integral de código pela LLM ECONOMIA: -80% de tokens ao enviar apenas assinaturas de funções MIT CST / AST Parser
1. O Que Faz

Parser incremental em C que extrai a hierarquia sintática de arquivos de código mesmo com erros parciais.

2. Como Funciona (Mecânica Interna)

Gera Concrete Syntax Trees (CST) ultra-rápidas em C nativo com parsing incremental: se você alterar 1 linha, ele reanalisa apenas aquele nó da árvore sem reprocessar o arquivo todo.

npm install -g tree-sitter-cli && tree-sitter parse arquivo.py
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Escreva um script em Node ou Python que roda queries S-expression do Tree-sitter.
2. Extraia apenas as declarações de class, def e docstrings do projeto.
3. Alimente seu agente com esse esqueleto sintático: ele saberá tudo o que existe no projeto usando apenas 2% dos tokens.

Especificação & Realidade
Consumo de RAM irrisório (< 5MB)

Por que é ouro: Permite criar ferramentas que alimentam o agente apenas com o mapa de símbolos das dependências.

tree-sitter.github.io
08

SGLang (RadixAttention)

SUBSTITUI: Recomputação cara de KV-cache ECONOMIA: 5x mais rápido em chats com histórico longo Apache-2.0 Inference Engine
1. O Que Faz

Implementa cache de prefixo em árvore radix, reaproveitando a computação do system prompt e mensagens anteriores em 100%.

2. Como Funciona (Mecânica Interna)

Mantém uma estrutura de dados de árvore Radix na memória de GPU para armazenar o KV-cache de múltiplos requests. Quando um novo prompt compartilha um prefixo já visto, reutiliza os tensores diretamente da VRAM.

python -m sglang.launch_server --model-path Qwen/Qwen2.5-Coder-7B-Instruct
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Inicie o servidor SGLang na sua máquina com GPU.
2. Configure seus agentes e subagentes para usarem a porta do SGLang.
3. Como os agentes repetem as mesmas 2.000 palavras de instruções de governança a cada turno, o processamento desse prefixo é instantâneo.

Especificação & Realidade
VRAM estática de GPU / Throughput massivo

Por que é ouro: O melhor motor para esteiras de subagentes que compartilham instruções de sistema extensas.

github.com/sgl-project/sglang
Parte 4 · A Regra de Ouro

Como operar essa pilha com estabilidade

Diretrizes para rodar ferramentas no seu próprio servidor com resiliência máxima e zero sobrecarga.

1. Isolamento em Containers Docker

Nunca instale ferramentas diretamente no sistema host sem isolamento de rede e volumes mapeados em disco seguro.

2. Proxy Reverso com Caddy / Traefik

Aponte a borda de rede para proxies leves com renovação automática de certificados TLS sem scripts manuais.

3. Backup Imutável com Restic / Borg

Programe snapshots diários dos volumes para armazenamento S3 remoto compatível para restauração rápida em caso de desastre.

4. Acesso Seguro via WireGuard / Headscale

Mantenha painéis de administração e bancos de dados fora da internet pública, acessíveis apenas pela VPN mesh interna.
