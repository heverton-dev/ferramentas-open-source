🎯 1. Foco Principal da Arquitetura

O propósito central desta arquitetura é estabelecer Soberania Tecnológica e Eficiência Industrial no ciclo de desenvolvimento assistido por IA (AIDD).

1. Economia Severa de Tokens

Elimina o desperdício de contexto em raciocínios prolixos (*Caveman*), logs gigantes de terminal (*Headroom*) e leitura indiscriminada de arquivos (*Lean-CTX*).

2. Determinismo Mecânico

Substitui promessas em prosa por scripts Python determinísticos que rodam no pre-commit com retorno exit 0/1.

3. Fonte Única Multi-IDE

A governança vive exclusivamente em .claude/ e é espelhada via links simbólicos para Cursor, Windsurf, OpenCode, VS Code e Cline.

4. Padrão Diamante R5

Artefatos e catálogos contam com design editorial justificado, 4 seções padronizadas e grids de 3 passos visuais acionáveis.

🏗️ 2. Como o Projeto Está Estruturado

O repositório é dividido em camadas de responsabilidade bem delimitadas:

seu-projeto/
├── .claude/                      ← [FONTE ÚNICA] Governança (CLAUDE.md), RTK.md, Skills e Subagentes
├── scripts/                      ← [USINA MECÂNICA] Hooks pre-commit, auditores R5/R18 e templates
│   ├── hooks/pre-commit          ← Gate Git: bloqueia segredos, suíte vermelha e entulho
│   ├── auditar_higiene_repo.py   ← Validador de paridade de hash entre espelhos
│   └── limpar_entulho.py         ← Saneador automático com 1 comando
├── output/ & docs/               ← [ENTREGA & ESPELHO] Listas técnicas em paridade estrita
└── AGENTS.md, .cursor/, etc.     ← [GERADOS] Espelhos atualizados via setup-links

⚖️ 3. Prós e Contras Desta Arquitetura

🟢 Prós (Vantagens)
  • Economia Financeira: Queda de até 90% no custo com APIs de LLMs.
  • Zero Alucinações de Qualidade: O pre-commit impede commit de código quebrado.
  • Liberdade de Ferramentas: Troque de IDE ou modelo de IA sem perder nenhuma regra.
  • Higiene Automatizada: A regra R18 não permite o acúmulo de arquivos temporários.
🔴 Contras (Trade-offs & Cuidados)
  • Disciplina no Commit: Não é permitido "commitar rápido sem testar".
  • Configuração de Links: No Windows, requer permissão de Administrador ou Modo Desenvolvedor.
  • Edição na Fonte: Nunca editar arquivos gerados diretamente (editar sempre em .claude/).

🚀 4. Como Gerar Novos Projetos ou Adequar Existentes

📦 Projeto Novo em 5 Minutos

Crie um repositório limpo, adicione a Fábrica Universal como submodule e rode o gerador de links:

# 1. Iniciar repositório
mkdir meu-projeto && cd meu-projeto && git init

# 2. Adicionar submodule da Fábrica
git submodule add https://github.com/Heverton-web/fabrica-universal.git fabrica-universal
git submodule update --init --recursive

# 3. Copiar infraestrutura base
cp -r fabrica-universal/.claude .
mkdir -p scripts && cp -r fabrica-universal/scripts/* scripts/

# 4. Configurar links e hook pre-commit (Windows ou Linux/Mac)
powershell .\scripts\setup-links.ps1 meu-projeto    # Linux: bash scripts/setup-links.sh meu-projeto
🔧 Adequando Projeto Legado Existente

Para projetos já em andamento, copie a pasta .claude/skills/, adicione a Seção 0 de Economia e as regras R1–R18 ao seu CLAUDE.md e ative o hook pre-commit:

python scripts/limpar_entulho.py
python scripts/auditar_higiene_repo.py
