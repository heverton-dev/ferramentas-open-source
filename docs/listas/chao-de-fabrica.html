Parte 1 · A Regra do Desastre

A fronteira entre autonomia e suicídio operacional

Infraestrutura própria não é sobre economizar centavos em máquina virtual — é sobre previsibilidade, portabilidade de dados e soberania. Quem constrói preso em serviços proprietários de nuvem descobre a fatura no dia do primeiro pico de tráfego.

Pilar I · O Tripé de Sobrevivência

Backup, Ingress e Monitoramento

Antes de subir qualquer aplicação, sua VPS precisa de três coisas inegociáveis que funcionem fora da máquina onde o dado vive:

  • Backup imutável e fora do host: Restic ou Borg com destino S3 compatível / rsync. Se o host for deletado, a restauração é 1 comando.
  • Borda e TLS determinístico: Caddy ou Traefik com renovação automática Let's Encrypt / ZeroSSL sem scripts manuais de cron.
  • Observabilidade sem devorar RAM: VictoriaMetrics + Netdata consumindo menos de 150MB combinados.
Pilar II · O Perigo das Licenças Predatórias

O êxodo das licenças BSL e FSL

A década de 2020 viu a morte do open source ingênuo em infraestrutura. Gigantes trocaram licenças para fechar ecossistemas:

  • HashiCorp (Terraform/Nomad/Vault): Abandonaram MPL-2.0 por BSL 1.1 — use OpenTofu e alternativas verdadeiras.
  • Drone CI: Tornou-se proprietário após compra pela Harness — a comunidade migrou para o Woodpecker CI.
  • Sentry: Migrou para FSL (não é OSI Open Source) com restrições comerciais diretas.

01

Coolify

Apache-2.0 PaaS Self-Hosted · Next.js / Laravel / Docker
O que entrega

Uma central completa de deploy idêntica ao Heroku/Render/Vercel rodando em um único comando no seu próprio servidor. Suporta deploy automático a partir do GitHub/GitLab, gestão de múltiplos bancos de dados com backup automatizado, certificados SSL automáticos e suporte a Dockerfile e Docker Compose nativos.

curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
Especificação & Realidade
~350 MB RAMem repouso (UI + Traefik + Postgres interno)

Atenção operacional: O Coolify usa Traefik por baixo. Não instale outro web server na porta 80/443 da mesma máquina sem configurar portas alternativas para evitar conflitos de bind.

github.com/coollabsio/coolify
02

Dokku

MIT Mini-PaaS CLI · Bash / Docker / Herokuish
O que entrega

O mini-PaaS mais maduro e minimalista do ecossistema. Funciona inteiramente via SSH e git push dokku main. Não roda nenhum daemon pesado ou interface web em segundo plano: ao receber o push, constrói o container, configura o proxy reverso e desliga os processos de build.

wget -NP . https://dokku.com/bootstrap.sh && sudo DOKKU_TAG=v0.34.12 bash bootstrap.sh
Especificação & Realidade
< 20 MB RAMem repouso (apenas daemons de sistema/nginx)

Ideal para VPS de 512MB: Para quem domina terminal, é o motor mais estável e previsível que existe há mais de 10 anos sem quebras de compatibilidade.

github.com/dokku/dokku
03

Caddy

Apache-2.0 Web Server & Reverse Proxy · Go
O que entrega

Servidor web e proxy reverso de alta performance escrito em Go que obtém e renova certificados TLS automaticamente sem intervenção humana. Uma configuração reversa completa cabe em apenas 3 linhas de texto no Caddyfile com suporte nativo a HTTP/2 e HTTP/3.

# Caddyfile
app.seudominio.com {
    reverse_proxy 127.0.0.1:3000
}
Especificação & Realidade
~30 MB RAMem repouso, escalando sob demanda com zero garbage collector pauses

Fim do certbot: Substitui Nginx + Certbot com muito menos atrito de configuração e sem dependência de runtimes Python externos.

github.com/caddyserver/caddy
04

Traefik

Apache-2.0 Edge Router Dinâmico · Go
O que entrega

Roteador reverso voltado a microserviços e ecossistemas orientados a containers. Detecta novos containers em execução escutando o socket do Docker e cria rotas, balanceamento de carga e certificados SSL automaticamente com base em labels declaradas no docker-compose.yml.

docker run -d -p 80:80 -p 443:443 -v /var/run/docker.sock:/var/run/docker.sock traefik:v3.1
Especificação & Realidade
~45 MB RAMem repouso com centenas de rotas dinâmicas

Cuidado com o socket: Montar /var/run/docker.sock expõe privilégios de root ao container. Em produção compartilhada, use socket proxies seguros.

github.com/traefik/traefik
05

Restic

BSD-2-Clause Backup Criptografado & Deduplicado · Go
O que entrega

Ferramenta de backup que trata cada snapshot como um sistema de arquivos completo enquanto armazena apenas os blocos únicos modificados. Criptografia ponta a ponta por padrão usando AES-256 e Poly1305. Suporte nativo a S3, Wasabi, B2, SFTP e diretórios locais.

restic -r s3:s3.amazonaws.com/meu-bucket init
restic -r s3:s3.amazonaws.com/meu-bucket backup /var/www/dados
Especificação & Realidade
Binário únicoexecuta sob demanda via cron / systemd timer e encerra

Imutabilidade real: Combinado com Object Lock no S3 ou repositórios append-only, impede que malwares ou sequestradores de dados apaguem seus backups anteriores.

github.com/restic/restic
06

BorgBackup

BSD-3-Clause Backup com Deduplicação Extrema · C / Python
O que entrega

O padrão ouro de deduplicação chunk-level para servidores Linux. Comprime dados com zstd/lz4 antes de gravar e suporta montagem de snapshots como sistema de arquivos via FUSE para recuperação pontual de arquivos individuais sem precisar baixar o repositório inteiro.

borg init --encryption=repokey-zstd /mnt/backup/meu-repo
borg create /mnt/backup/meu-repo::'{now}' /etc /home /var/lib/docker/volumes
Especificação & Realidade
CLI sob demandautiliza recursos apenas durante a janela de compressão

SSH nativo: Excelente para backups servidor-a-servidor via SSH com Borg instalado em ambas as pontas para máxima velocidade de rede.

github.com/borgbackup/borg

VictoriaMetrics

Banco de dados de séries temporais ultra-otimizado que aceita ingestão e consultas de Prometheus (PromQL) e InfluxDB. Foi desenhado para resolver o calcanhar de Aquiles do Prometheus: o consumo descontrolado de memória RAM e a alta taxa de I/O em disco.

~50 MB RAMem operação normal (vs 400MB+ de um Prometheus padrão)

WireGuard

GPL-2.0 Kernel VPN Protocol · C puro
O que entrega

O protocolo de VPN mais rápido e seguro do mundo moderno, integrado diretamente ao kernel do Linux (versões 5.6+). Com menos de 4.000 linhas de código (contra 100.000+ do OpenVPN), é auditável, quase invisível na rede e consome uma fração irrisória de energia e processamento.

sudo apt install wireguard

Especificação & Realidade
Zero userspace RAMroda no espaço de kernel com throughput próximo à velocidade de linha

Criptografia moderna: Utiliza Curve25519, ChaCha20-Poly1305 e BLAKE2s. Troca de chaves rápida e reconexão instantânea em trocas de rede.

wireguard.com

Parte 5 · O Método

Como a ordem foi montada

Uma esteira de DevOps não começa instalando dashboards — começa garantindo que a máquina se recupera de uma falha de hardware em menos de 15 minutos.

1. Camada de Resiliência

Primeiro configura-se Restic e Headscale/WireGuard. Se o SSH público for desligado e houver cópia imutável do disco fora da nuvem, nenhum ataque paralisa a empresa.

2. Camada de Roteamento

Instalação do Caddy ou Traefik. A borda assume portas 80/443 e passa a emitir certificados TLS com renovação transparente e sem scripts quebradiços.

3. Motor de Aplicação

Escolha do motor: Dokku para máquinas pequenas/médias sem fricção ou Coolify para times que demandam interface visual e múltiplos bancos.

4. Telemetria Leve

Fechamento com VictoriaMetrics e Uptime Kuma externo. Você descobre lentidões antes do cliente sem estourar o orçamento em SaaS de monitoramento.

Auditoria realizada de acordo com as diretrizes de governança da Fábrica Universal. Todos os 20 projetos foram verificados quanto a licenças OSI, ausência de telemetria forçada e viabilidade real em VPS Linux padrão.
