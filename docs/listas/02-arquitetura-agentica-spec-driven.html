01

Skill: spec-driven-contracts (Spec-Kit)

SUBSTITUI: Desenvolvimento desgovernado por IA ECONOMIA: Economiza semanas de retrabalho em código quebrado MIT / SDD Skill Spec-Driven Dev Skill
1. O Que Faz

Framework formal que bloqueia a escrita de código até que o contrato de especificação (SPEC -> PLAN -> TASKS) e os critérios de aceite estejam aprovados.

2. Como Funciona (Mecânica Interna)

Estrutura o ciclo agêntico em 3 fases rígidas: 1) SPEC.md (Entradas, saídas esperadas e contratos de API); 2) PLAN.md (Quebra arquitetural em tarefas atômicas); 3) TASKS.md (Execução passo a passo com testes).

# SPEC.md -> PLAN.md -> TASKS.md -> EXECUÇÃO
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Antes de pedir código à IA, crie SPEC.md definindo contratos e tipos.
2. Peça ao agente para emitir o PLAN.md detalhando cada módulo.
3. O agente implementa arquivo por arquivo, validando cada etapa contra os critérios de aceite.

Especificação & Realidade
Contratos formais / 0 RAM

Por que é ouro: Garante que a IA nunca comece a gerar arquivos sem saber exatamente o critério de aceite.

github.com/github/spec-kit

Skill: test-first-tdd

SUBSTITUI: Código sem cobertura de testes ECONOMIA: Reduz 90% dos bugs em produção MIT / TDD Skill TDD Gatekeeper Skill
1. O Que Faz

Impede o agente de escrever a lógica de negócio antes de criar e executar o teste unitário correspondente que falha (Red-Green-Refactor).

2. Como Funciona (Mecânica Interna)

Injeta uma restrição no ciclo de execução: para toda nova feature ou bug fix, o agente deve gerar o arquivo de teste unitário primeiro (pytest, vitest, cargo test) e só pode prosseguir quando o teste falhar com a asserção correta.

# Regra: 'Teste primeiro (Red) -> Implementação (Green) -> Refatoração'
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Solicite uma funcionalidade (ex: validação de CPF).
2. O agente gera `tests/test_cpf.py` com 10 casos extremos.
3. Executa a suíte (falha esperada), implementa a função `validar_cpf()` e reexecuta até obter 100% de sucesso.

Especificação & Realidade
0 MB RAM / Disciplina TDD

Por que é ouro: Testes unitários escritos antes da implementação forçam a IA a pensar no contrato e nos casos de borda.

github.com/topics/tdd-skills

Skill: architect-gatekeeper

SUBSTITUI: Acoplamento e quebra de SOLID por IA ECONOMIA: Zero débitos técnicos cumulativos MIT / Architecture Skill Architecture Gatekeeper
1. O Que Faz

Avalia o impacto arquitetural de cada alteração: verifica acoplamento aferente/eferente, coesão modular e conformidade com Clean Architecture.

2. Como Funciona (Mecânica Interna)

Executa análise estática de imports e chamadas de classes. Se uma camada de domínio tentar importar diretamente um driver de banco de dados ou framework web, o gatekeeper bloqueia a alteração com `exit 1`.

# Regra: 'Camadas internas não conhecem camadas externas (Dependency Inversion)'
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. O agente arquiteto valida os diagramas e contratos antes do commit.
2. Se uma dependência circular for detectada, o gatekeeper força a criação de uma interface desacoplada.
3. Garante que monorepos e microserviços permaneçam manuteníveis ao longo de meses.

Especificação & Realidade
Análise estática de dependências

Por que é ouro: Evita que agentes autônomos transformem bases limpas em monolitos espaguete com imports cruzados.

DSPy Assertions

SUBSTITUI: Retentativas manuais com try/except ECONOMIA: -60% de chamadas com erro semântico MIT Self-Correcting Pipelines
1. O Que Faz

Mecanismo que injeta asserções lógicas dentro de pipelines de LLM, disparando backtracking automático caso a saída viole restrições de negócio.

2. Como Funciona (Mecânica Interna)

Utiliza as primitivas `dspy.Assert` e `dspy.Suggest`. Se uma asserção falhar durante a execução, o compilador envia o feedback do erro diretamente para o módulo anterior no grafo e reexecuta com novos parâmetros.

Smolagents (Hugging Face)

SUBSTITUI: Tool calling inflado em JSON ECONOMIA: -40% de tokens em chamadas de ferramentas Apache-2.0 Code-First Agent Library
1. O Que Faz

Biblioteca minimalista da Hugging Face onde os agentes escrevem e executam código Python puro para chamar ferramentas em vez de JSON.

2. Como Funciona (Mecânica Interna)

Executa o paradigma *CodeAgent*: o modelo escreve blocos de código Python padrão com condicionais e loops para interagir com múltiplas ferramentas em uma única etapa, em vez de fazer N chamadas sequenciais de JSON.

pip install smolagents
3. Como Usar no Dia a Dia (Passo a Passo Prático)

1. Crie um agente: agent = CodeAgent(tools=[busca_web, gerador_imagem], model=model).
2. O agente resolve tarefas complexas escrevendo um pequeno script Python.
3. Executa as ações em lote economizando turnos de ida e volta.

Especificação & Realidade
< 30 MB RAM / Ultra-leve

Por que é ouro: Escrever código Python é mais natural e compacto para LLMs de programação do que gerar schemas JSON gigantes.

Como operar essa pilha com estabilidade

Diretrizes para rodar ferramentas no seu próprio servidor com resiliência máxima e zero sobrecarga.

1. Isolamento em Containers Docker

Nunca instale ferramentas diretamente no sistema host sem isolamento de rede e volumes mapeados em disco seguro.

2. Proxy Reverso com Caddy / Traefik

Aponte a borda de rede para proxies leves com renovação automática de certificados TLS sem scripts manuais.

3. Backup Imutável com Restic / Borg

Programe snapshots diários dos volumes para armazenamento S3 remoto compatível para restauração rápida em caso de desastre.

4. Acesso Seguro via WireGuard / Headscale

Mantenha painéis de administração e bancos de dados fora da internet pública, acessíveis apenas pela VPN mesh interna.
