1. O Que Faz & Como Funciona

# SPEC.md -> PLAN.md -> TASKS.md -> EXECUÇÃO

Por Que é Ouro / Veredito

Garante que a IA nunca comece a gerar arquivos sem saber exatamente o critério de aceite.
