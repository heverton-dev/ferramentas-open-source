Parte 1 · A Soberania do Dado

A fronteira entre IA parceira e vazamento de segredos industriais

Usar APIs proprietárias de nuvem parece conveniente até que suas regras de negócio, segredos e chaves trafeguem em servidores de terceiros sob termos de serviço mutáveis. A pilha moderna permite rodar modelos de estado da arte dentro da sua rede com desempenho superior.

Pilar I · Inferência e RAG Privado

O Runtime Local e os Vetores Autônomos

A espinha dorsal do desenvolvimento com IA exige três componentes que rodem isolados sem internet:

  • Motor de Execução: Ollama para setup imediato e vLLM para concorrência pesada de requests com PagedAttention.
  • Banco Vetorial em Rust/C++: Qdrant ou Chroma sem cobranças mensais por pods ou limites de dimensão.
  • Gateway & Gateway Fallback: LiteLLM para unificar chamadas em formato compatível com OpenAI e chavear entre modelos locais e APIs sob demanda.
Pilar II · Agentes & Pair Programming

Assistentes que operam no seu repositório Git

Editores proprietários cobram mensalidades caras e capturam seus comandos. A alternativa comunitária devolve o controle ao desenvolvedor:

  • Aider: Pair programming via terminal gerando commits semânticos no Git com base no AST.
  • Continue.dev: Extensão aberta para VS Code/JetBrains compatível com Ollama e modelos locais.
  • Langfuse: Tracing aberto de tokens, latência e custo por prompt sem enviar dados a terceiros.

Auditoria técnica de consumo, stack e comando de inicialização reproduzível.

01

Ollama

MIT LLM Runtime · Go / C++ (llama.cpp)
O que entrega

A forma mais simples e robusta de executar modelos de linguagem localmente com quantização (GGUF), offload de camadas para GPU Nvidia/AMD/Apple Silicon e servidor HTTP nativo compatível com a API da OpenAI na porta 11434.

curl -fsSL https://ollama.com/install.sh | sh
ollama run qwen2.5-coder:7b
Especificação & Realidade
VRAM / RAM dinâmica~4.5 GB VRAM para modelos 7B Q4_K_M; quase zero em idle

Ponto alto: Gerencia o ciclo de vida do modelo descarregando pesos da VRAM após 5 minutos de inatividade para liberar sua GPU.

github.com/ollama/ollama
02

vLLM

Apache-2.0 Production Inference Engine · Python / CUDA / C++
O que entrega

O motor de inferência padrão da indústria para ambientes de produção com múltiplos usuários concorrentes. Sua tecnologia de PagedAttention gerencia a memória KV-cache como a paginação de memória virtual de um SO, multiplicando o throughput em até 10x.

vllm serve Qwen/Qwen2.5-Coder-7B-Instruct --port 8000 --max-model-len 8192
Especificação & Realidade
Alocação de VRAM estáticaReserva até 90% da GPU para KV-cache contínuo e batching paralelo

Quando usar: Excelente para backends de API e empresas com tráfego simultâneo. Para uso individual na máquina local, prefira o Ollama.

github.com/vllm-project/vllm

MIT Self-Hosted AI Workspace · Python / Svelte
O que entrega

A melhor e mais completa interface web auto-hospedada para IA. Integração nativa com Ollama e OpenAI, suporte a RAG com upload de documentos, geração de imagens, pipelines de moderação, autenticação de usuários e compartilhamento de prompts customizados.

~150 MB RAMem repouso (processo backend FastAPI + SQLite)

Segurança corporativa: Permite isolar completamente os chats dos membros da equipe com controle de permissões por grupo e histórico em disco próprio.

github.com/open-webui/open-webui

LiteLLM Proxy

MIT AI Gateway & Fallback Router · Python
O que entrega

Proxy reverso universal que padroniza entradas e saídas de mais de 100 provedores de LLM no formato oficial da OpenAI. Oferece chaveamento de chaves, rotação de provedores, limite de gastos (rate limiting / cost tracking) e fallback automático se um modelo falhar.

Especificação & Realidade
~70 MB RAMem repouso processando requisições assíncronas

O escudo contra lock-in: Mude de fornecedor (ou troque nuvem por servidor local) mudando apenas a rota no LiteLLM, sem reescrever 1 linha da sua aplicação.

github.com/BerriAI/litellm

Parte 5 · O Método

Como construir uma esteira de IA soberana

A ordem de montagem recomendada para times que valorizam privacidade, previsibilidade de custos e controle técnico total.

1. Runtime & Gateway

Instale o Ollama no servidor local/GPU e posicione o LiteLLM Proxy na frente. Toda a sua equipe passa a consumir uma API unificada compatível com OpenAI.

2. Base Vetorial & Ingestão

Suba o Qdrant e configure pipelines com Unstructured. Seus documentos privados são particionados e indexados sem jamais sair da sua rede local.

3. IDE & Assistência

Instale Continue.dev e Aider para os desenvolvedores. O ganho de produtividade acontece direto no fluxo Git sem envio de código para servidores externos.

4. Observabilidade & Avaliação

Conecte o Langfuse no LiteLLM para monitorar cada token, custo e latência em tempo real, auditando a qualidade e prevenindo alucinações.

Auditoria realizada de acordo com as diretrizes de governança da Fábrica Universal. Todos os 20 projetos foram verificados quanto a licenças livres, independência de nuvens proprietárias e capacidade de execução autônoma.
